## 输入法恢复与界面

同一个桥接进程恢复 HID／RSD 后，新的 ready 可能改变实际键盘能力与状态，原先两个恢复入口没有重新核对。现在核对所有当前在线通道，任一异常则提示不可用；所有通道恢复后才清除过期的不可用提示，保存失败等其它错误不因一次健康 ready 被清掉。

后台健康 HID 轮换原先会采纳不匹配用户输入法偏好的候选通道，可能静默把隐藏变显示或反过来。新逻辑拒绝不匹配的健康候选、关闭候选并保留旧路线。强制故障恢复仍可回退并通过新 ready 报告实际能力与状态。该修复新增回归先在旧实现明确失败。

按用户要求去掉输入法按钮下方的常驻说明与成功提示。按钮本身显示当前选择，说明放入悬停提示；异常提示位于按钮上方且仅出错时显示，正常状态不占额外一行。

## 独立窗口圆角

独立窗口此前在创建时缓存圆角半径和指数，后续识别到机型或源屏幕改变时只更新机框，基础圆角未重新计算。主预览已正确更新，遗漏限于独立窗口。修复根据实际型号及源尺寸重新选择基础轮廓，保留用户是否启用圆角、机框以及全屏意图。回归覆盖未知型号到 iPhone 17、Duo 内外屏及旋转等切换；非对称外屏仍沿用上一轮明确的保守策略。
