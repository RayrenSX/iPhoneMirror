# 近期 iPhone 设备圆角数据审查

本轮核对当前内置目录中的 iPhone 16、17、18 Pro 系列，以及 Air、16e／17e 和 Duo 两块屏幕。设备标识、原生面板尺寸来自 `config/apple-display-catalog.json`；素材及其来源、哈希、屏幕区域来自 `config/apple-device-frames.json`。本轮没有更改官方面板尺寸。

## 数据修正

原先这些机型大多共用 Dynamic Island 的同一归一化半径和超椭圆指数，Pro Max、Plus 和 Duo 因此不能准确匹配各自屏幕轮廓。17e（`iPhone18,5`）还遗漏了刘海例外，误用了 Dynamic Island 轮廓。

常规新机改为从当前内置屏幕遮罩可重复拟合的专属参数。对四角 44 个归一化高度取轮廓，以渲染器超椭圆距离最小二乘搜索半径与指数；再逐行扫描四角边界做密集验证。Air 额外最小化密集边界的最坏误差。两参数必须配套使用，不能只比较归一化半径数值。

所有这些轮廓的 HWND 裁切半径与着色器半径保持一致，避免先前双轮廓留下黑边。常规机型和 Duo 内屏对原始遮罩的最坏边界差约 1.1–1.44 原图像素；这是素材拟合误差，不是 Apple 公布的机械圆角公差，也不代表每款都已真机逐像素校准。

16e 和 17e 使用保守的现代刘海轮廓，沿用刘海参数（0.1580、2.25），并统一 HWND／着色器轮廓。这两款当前专属机框是项目自绘，不能拿自绘图反推真实物理圆角，因此不计入精确素材拟合通过组。旧刘海机型和 iPad 的参数未在本轮扩改。

## 来源与局限

16／17 系列原图来自内置记录的 fastlane Apple 机框 PNG；18 Pro 系列和 Duo 来源记录为 Apple 设计资源 DMG。Air 当前记录为第三方专属素材，其屏幕区 1290×2796 与官方目录 1260×2736 不同，本轮只按归一化轮廓拟合，不用素材尺寸覆盖官方面板数据。来源、原图 SHA256、框图和遮罩的完整性沿用现有资产校验。

Duo 外屏的四角不是同一轮廓：在距顶部 1% 短边处，素材左角约缩进 2 像素、右角约 109 像素。现有单半径／指数架构无法准确表示左右不同圆角。此项明确未通过精确轮廓校准；暂时保留矩形裁切，避免错误的对称圆角丢失有效画面，不将平均拟合当成已支持。

Duo 内屏比例为 2007／2853，外屏为 1398／2034，二者的中点约 0.69539283。按与机框目录相同的屏幕比例判定内屏，兼容横竖旋转和缩放；无尺寸或其它未知形状使用保守矩形。后续精确支持外屏需独立四角参数或屏幕遮罩路径，本轮没有扩展 Core API。

## 验证

`--device-corner-clipping` 增加逐个近期目录标识与两块 Duo 屏幕的检查，明确区分已验证原图拟合、估计刘海参数及不支持的非对称外屏。它比较真实 Win32 HWND 区域和着色器轮廓，覆盖四角、多个预览尺寸、横竖屏及 DPI；并对已校准组逐行扫描原始遮罩，要求最坏距离小于 1.5 原图像素。Logic 回归检查 17e 例外、Duo 内屏旋转缩放、外屏／未知尺寸回退，以及未知手机保守通用行为。

可重复拟合程序及本轮原始测量位于 `work/iphone17-corners-20261117/`。最终通过结果以交付 `BUILD-INFO.json` 中的日志和源码哈希为准。
