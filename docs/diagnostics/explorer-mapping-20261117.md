# Windows 资源管理器映射与设备管理白框

在 `main` 集成工作区实现，完整交付包括当前驱动管理器和新文件桥接程序。采用 Windows 自带 WebClient，将手机开放的媒体文件服务映射为当前用户的临时网络盘，开关默认关闭。此功能不映射 iPhone 完整文件系统，不安装第三方文件系统驱动，不修改服务配置、认证策略或传输上限。

## 使用与范围

设备管理 → 文件 → 媒体文件中开启“映射到资源管理器”。成功后显示分配的盘符和“打开”按钮，可在资源管理器中浏览、复制进出、创建目录、重命名、删除。复制进入此服务不会自动导入照片或音乐资料库。隐藏面板或切换页面不会断开映射；切换设备、控制连接断开／代次变化或退出程序时撤销本程序创建的映射。映射权限沿用当前手机的文件服务与用户操作归属。

Windows WebClient 在本机存在并运行，当前 `FileSizeLimitInBytes` 为 50,000,000 字节。开关提示显示系统当前单文件下载上限，上传也采用相同上限；本功能不静默修改注册表。系统组件缺失或禁用时给出失败反馈。Windows 已弃用该组件，未来系统可能需要不同映射后端；本版不自动安装替代驱动。

## 实现

每个映射拥有随机本机端口和随机能力路径，仅监听 IPv4 loopback。请求校验 Host、路径和浏览器 Origin／Fetch 标记；不会将能力 URL、手机文件名或本地上传路径写入普通日志。WebDAV 提供按需读取和有界分块、HEAD／Range／目录属性、PUT／MKCOL／MOVE／DELETE、条件冲突和短期独占锁。上传使用用户私有临时文件，结束或取消后清理；没有把手机目录全部下载到电脑来伪装映射。

文件服务固定设备、宿主和输入代次，不会在旧盘符下悄悄切到另一个手机或新连接。映射请求有界串行，写操作不自动重试。Python 新增的精确目标操作均为私有动作，保留现有面板导入避重名和手动删除语义。写入先完成临时文件，再核对目标快照并重命名；AFC 没有原生比较交换，因此不声称远程条件写具有绝对原子性。递归删除先有界预检，执行中断连仍可能部分完成，不自动重试。

## 白框

已在真实 WPF 隔离探针复现：设备管理外层 `ContentControl` 是默认可聚焦的额外 Tab 目标，系统焦点样式在整个面板绘制细白方框。仅将主界面和开发工具的两个承载容器设为不可聚焦／非 Tab 目标并清容器焦点样式，按钮、输入框和列表操作的键盘反馈保留。前后截图位于 `work/device-hub-white-frame-20261117`。

## 验证

真实 Windows 临时映射测试使用内存文件服务，已验证挂载、英中文文件浏览和读取、创建目录、写入读回、重命名、删除、卸载、取消后的迟到连接清理，以及盘符被复用时旧实例不会撤销新映射。未在手机上执行这些写入测试。

另以 Windows Shell 实际递归复制整目录至隔离电脑目录，核对英文、中文与嵌套文件内容通过。该系统的 .NET 直接目录枚举结果会含尾 NULL，按枚举字符串直接 `File.Open` 会失败；Win32 枚举及 Windows Shell 复制正常，这是 [.NET 官方记录的 WebDAV 互操作问题](https://github.com/dotnet/runtime/issues/46723)，不通过篡改手机文件名处理。直接使用此映射的 .NET 程序可能遇到该限制。WNet 没有原子“比较归属后撤盘”接口，当前紧邻撤盘前检查随机远端归属，无法对外部程序在极窄窗口重映射提供绝对原子保证。

Socket 回归验证真实 HTTP 读写、锁、条件覆盖、XML 与路径边界、超过 4 GiB 偏移的有界 Range、浏览器写入拒绝、连接取消和上传清理。适配器验证原始修改时间快照、逐块一致性、分页、有界排队、精确写参数和错误转换。Python 新旧文件／设备服务与运行时检查共 48 项通过；新打包桥接 13 模块、13 功能和 863 文件清单校验通过。界面回归覆盖白框容器、映射开关默认／忙碌／设备隔离／错误／断连关闭，以及原有设备管理五语言、明暗主题、紧凑和简易模式。

映射生命周期回归确认：等待旧清理期间已登记可取消身份，切换设备立即撤销旧请求，旧完成不会覆盖新映射；清理资源逐项容错且等待晚返回的盘符；桥接代次变化、退出及手动操作占用均有明确处理。曾遇到隔离测试自动弹出机型建议窗口而暂停，已按既有设备管理 fixture 隔离该 UI，仅验证生产的映射及选中设备回调。

实际手机映射、资源管理器显示及白框消失还需最终交付上的用户实测。最终构建、测试与文件哈希以交付 `BUILD-INFO.json` 为准。
