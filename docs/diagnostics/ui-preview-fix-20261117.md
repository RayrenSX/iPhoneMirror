# 界面整理与无线重连预览修复

本次处理首次使用助手关闭按钮过小、投屏侧栏按钮堆叠、禁用按钮实灰背景，以及描述文字开关遗漏。过程中用户报告切换原画后持续黑屏，同时显示正常帧率，因此保留运行现场并审查日志及会话切换路径。

## 预览黑屏

18:16:31 新的无线会话 h4 收到 994×2160 视频帧，随后 AirPlay 视频回调持续成功。预览却只初始化为 1×1，整个会话没有 `session_preview_attach`，销毁时渲染帧数为零；这与此前 h2 正常附加到 761×685 窗口并渲染的记录不同。18:18:13 手机断开，18:18:51 回退有线来源，不将其称为原画恢复。

重建无线会话时，旧的原生预览选择已被清空，新句柄仅写入会话表。设备列表保留同一个设备对象，重复选择会提前返回，因而遗漏新句柄的预览选择与通知。修复应在当前选中设备的会话句柄改变时同步原生预览选择，而不依赖设备对象发生变化；非选中来源不能抢占当前预览。

原始证据的有限摘要在 `work/original-black-20261117/log-review.md` 与 `safe-preview-timeline.log`，未在报告中公开设备身份或网络地址。针对性回归使用真实 ViewModel 和会话表替换事件，保留稳定设备对象，检查选择、通知、清理和其它来源隔离；不把合成句柄测试冒充手机实际重连。

## 界面调整

首次使用助手的普通文字 × 改为与其它子窗口一致的 18px Dismiss 图标，沿用 40×40 点击区域和关闭流程。

助手的步骤条、内容和底部导航统一中心轴与最大内容宽度。去掉单张工具卡的单侧留白，双卡使用对称间隔；返回和下一步等宽，跳过操作居中。复用原有滚动容器处理最小窗口，而不为对齐增加新的页面层级。

投屏侧栏改为左对齐功能列表，统一 18px 图标、固定图标列和 44px 行高，通过两处分隔线区分三组功能。九项操作、快捷栏入口及启用条件保持一致。次要按钮禁用状态改为低透明度底色、轻边框和弱化文字；图标/透明按钮保持透明，主操作按钮仍保留原有层级。深浅主题均使用动态资源。

界面描述默认已经隐藏，本次保留这一默认值与已有个人选择，补齐代理帮助、设备范围、机框说明、开发者工具及部分子窗口说明的实时开关。必填标签、状态、错误和首次使用助手核心操作说明保持可见。

按用户要求移除反控设置底部“清除所有蓝牙绑定数据”按钮及其无入口事件处理。正常设备绑定管理继续使用原有流程。

## 手机输入法

“反控 → 键盘与快捷键”新增“手机输入法：显示／隐藏”按钮，默认显示，可在未连接时保存偏好，有线与无线控制建立、恢复时应用。运行中对当前已连接的对应控制通道发送明确请求；不改变蓝牙控制行为。远端拒绝或设置保存失败时回滚；若回滚失败则报告未恢复，不声称成功。

显示模式优先使用 iOS 已存在的 512 键盘表面，避免将自建硬件键盘注册为外接键盘而自动收起输入法。隐藏模式才创建本通道拥有的硬件键盘服务；切换前释放已按住的键，恢复显示时仅移除本通道创建的服务，保护系统服务。协议使用能力、请求编号、会话代数及实际可见状态确认；不确定结果会退役该输入通道。缺少系统表面或系统拒绝创建时明确标记不支持，保留 PC 输入功能但不假报输入法状态。

## iPhone 17 简易预览圆角

设备轮廓的窗口区域半径与渲染半径不一致，留下四角黑色外带。本轮对已校准的近期机型统一两层轮廓；旧刘海和 iPad 参数不扩改。回归通过真实 Win32 区域与渲染曲线的像素边界比较验证，包含横竖屏和多种缩放尺寸；诊断合成图明确不冒充手机截屏。

用户随后要求核查近期机型。以项目内有来源记录的设备遮罩重新测量常规 iPhone 16/17/18 系列和 Air，检查硬件标识、屏幕尺寸及轮廓；不同大小机型不再一概宣称同一拟合精确。Apple 规格页用于确认屏幕类型与尺寸，例如 [iPhone 17](https://support.apple.com/en-us/125089)、[iPhone 17e](https://support.apple.com/en-us/126470)、[iPhone 18 Pro](https://support.apple.com/en-us/148590)。数值曲率来自遮罩拟合，不是这些规格页提供的官方机械半径。

[iPhone Duo 规格](https://support.apple.com/en-us/148588)区分内外屏；项目外屏遮罩还存在左右不对称的圆角。当前统一曲率渲染器不能精确表达该外屏，不用平均拟合冒充正确，也不计入“精确吻合”通过组。数据检查记录该限制，并优先保留完整画面以避免错误裁切。

最终测试、截图与交付哈希以本次 `BUILD-INFO.json` 为准。需要在新版上实际重试原画连接，确认现场黑屏不再出现。
