# Issue #77：设置项快捷键

关联 [Issue #77](https://github.com/RayrenSX/iPhoneMirror/issues/77)。返回 [Issue 索引](README.md)。

## 行为

快捷键设置的滚动内容底部增加“更多设置项快捷键”，支持添加、删除设置项绑定，
目前接入窗口透明度和置顶。每行选择设置项、快捷键及按住时的目标值，和原有快捷键一起保存。
透明度取值 10%–100%；日常透明度继续在独立窗口的“窗口 → 样式”中设置。

独立窗口在前台时按住快捷键，临时应用第二档值，松开恢复窗口原样式；无需开启任何反控。
键盘支持现有的功能键和组合键，鼠标支持右键、中键及侧键 1/2（已绑定的键不能重复分配）。
按住期间显式透明度优先于悬停不透明；松开后重新按当前基础透明度与悬停状态计算。
多键交叠采用最后按下的值，逐个释放后恢复仍在按住的值，最终回到当前基础值。
窗口失焦、关闭、输入所有权切换、打开编辑器或重新配置时撤销临时覆盖，不会覆盖基础值。

## 实现与范围

- 设置项绑定采用独立数据列表，旧配置默认空列表。保存失败回滚整套快捷键；加载时排除非法值、重复键和重复标识。
- 键盘复用现有按键路由的按下/松开生命周期；鼠标使用 Windows 低级钩子，保证反控关闭时仍能使用，移出窗口后松开也能恢复。
- 每次按下捕获原窗口，释放操作不会重新解析当前设备；后台应用、设置编辑器不会触发新动作。
- 只改变独立窗口的显示样式，不修改手机端画面、录屏、直播或其他窗口。
- 五种语言均提供入口、操作说明及目标值标签，沿用原有设置分类，不增加折叠组。

## 验证

`App.Runtime.Tests --setting-shortcuts <输出目录>` 覆盖按下/松开、连按、交叠、悬停优先级、
按住期间编辑基础值、失焦、输入交接、多窗口隔离、渲染失败、保存失败及成功重试、磁盘往返、
配置克隆、双向快捷键冲突和五语明暗主题渲染。
交叠测试还覆盖释放旧键再按下的顺序，临时值按显式序号排序，避免字典槽位复用改变优先级。
其中鼠标侧键使用 Windows 钩子链和鼠标事件注入，窗口焦点由测试提供受控快照；
窗口内容为合成 WPF 画面，没有向手机发送测试输入。

相关运行入口还包括 `--keyboard-router`、`--mouse-shortcuts` 和 `--preview-context-menu`；
