# Issue #60：关闭主窗口到托盘审查

审查日期：2026-10-25。需求来源：[Issue #60](https://github.com/RayrenSX/iPhoneMirror/issues/60)。

关闭到托盘的主体实现已包含在主线提交 `31acd8a`。本次在最新主线基础上复核，补齐映射草稿保留和五种语言的验收覆盖。最终审查未发现需要修改产品代码的问题。

## 行为确认

启用“关闭主界面时进入托盘模式”后，主窗口关闭被转换为临时隐藏，未保存的映射编辑器草稿会继续保留，不进入应用退出、草稿丢弃或投屏清理流程。

关闭到托盘默认关闭。启用后可从托盘恢复原来的完整或精简模式；明确退出和系统会话结束仍绕过关闭到托盘。临时收起不会改变下次启动的模式。

## 验证

- 新增真实 WPF 回归，分别覆盖完整、精简模式收起和恢复后的映射草稿内容、未保存状态及继续编辑能力；收起期间不要求放弃草稿，不启动应用退出。
- 新增 Boss 键回归：主窗口已在托盘时，独立原生媒体窗口仍可被 Boss 键隐藏和恢复，主窗口继续留在托盘。
- 托盘专项继续覆盖默认关闭、设置更新、重复关闭、独立原生媒体窗口保持可见、恢复入口、启动模式不变、明确退出及系统会话结束的关闭拦截策略。
- 托盘布局检查扩展到简中、香港繁中、台湾繁中、英文、日语，共五种语言和两种主题。
- Release 构建、App Logic、默认 App Runtime 和托盘专项通过；托盘专项无绑定诊断。

本次通过真实窗口及内存夹具验证，不要求连接手机；实际 USB/AirPlay 投屏连续性仍需用目标设备验收。现有 Boss 键逻辑继续独立于主窗口关闭路径。
