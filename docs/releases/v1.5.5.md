# iPhoneMirror v1.5.5

v1.5.5 重点改善高缩放 Windows 桌面上的界面可用性，以及国内和受限网络环境中的应用更新、Apple 驱动下载体验。本版本没有把 Apple 专有安装包打进 iPhoneMirror，运行时仍只从 Apple 官方 CDN 获取驱动文件。

## 主要更新

### 高 DPI 与窗口适配

- 主程序和驱动管理器会根据当前显示器的可用工作区自动限制窗口尺寸与位置。
- Windows 缩放比例较高、任务栏占用空间或使用不同 DPI 的多显示器时，窗口不再容易超出屏幕。
- DPI 改变后会重新校正布局，同时尽量保留用户已经有效的窗口位置和大小。

### GitHub 更新下载优化

- 应用更新支持 HTTP Range 多线程分段下载；服务器不支持 Range 或行为不一致时会自动回退到单连接下载。
- 可启用 GitHub 下载镜像回退，直连 GitHub Release 失败或速度过慢时依次尝试备用下载通道。
- 多线程下载会复用重定向后的可信 CDN 地址，减少每个分段重复跳转的开销。
- 所有更新安装包在启动前必须通过 SHA-256 校验。

### 更新安全边界

- 版本、文件名、下载地址和 SHA-256 等更新元数据只接受 GitHub 官方 API 或 `raw.githubusercontent.com`。
- 第三方镜像只能传输已经由官方元数据锁定 SHA-256 的文件字节，不能决定要安装的版本或校验值。
- 下载地址、重定向目标、文件大小和摘要不符合预期时会拒绝安装。

### Apple 驱动下载优化

- 驱动管理器会解析 Apple 官方 Windows Software Update Catalog，选择最新的 x64 `AppleMobileDeviceSupport64.msi`。
- 默认下载量由完整 iTunes 安装包约 208 MB 降至独立驱动 MSI 约 38.4 MB。
- Apple 驱动下载使用最多 8 个并发分段。在本次测试网络中，官方 CDN 分段下载约为 3.94 MB/s，旧 iTunes 完整包路径约为 0.3 MB/s；实际速度仍取决于运营商、地区和 Apple CDN 节点。
- 安装前会核对目录声明的精确文件大小、Apple 官方下载域名及 Authenticode 签名者。
- 如果独立 MSI 目录不可用、下载失败或校验不通过，仍保留 Apple 官方完整 iTunes 安装包作为兼容回退。

## 兼容性与行为

- 支持 Windows x64，安装版和便携版均继续提供。
- 更新镜像回退可在“关于/更新”设置中控制；关闭后只访问 GitHub 官方下载地址。
- Apple 驱动安装仍可能触发 Windows UAC，现有 Apple 组件正在运行时也可能要求重新启动。
- iPhoneMirror 不随安装包分发 Apple Mobile Device Support、iTunes 或其他 Apple 专有二进制文件。

## 验证范围

- Release 配置完整构建。
- 原生测试 6/6。
- 应用逻辑、运行时和驱动安装器测试。
- 多线程范围请求、字节级重组、Range 忽略与异常回退测试。
- GitHub 官方元数据回退、镜像下载及 SHA-256 强制校验测试。
- Apple Catalog 最新包选择、恶意主机拒绝、包大小与签名验证。
- 高 DPI、超大窗口和多显示器负坐标布局测试。
- 中英文资源与本地化验证。

## 已知限制

- 下载速度仍受当地网络、代理、杀毒软件扫描和远端 CDN 状态影响，多线程不能突破网络本身的带宽或限速。
- 某些企业代理会禁用或重写 HTTP Range，此时下载器会自动使用单连接，速度可能较低。
- Apple 随时可能调整软件更新目录格式或 CDN 策略；目录路径失效时会使用完整 iTunes 官方包回退。
