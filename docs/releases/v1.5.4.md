# iPhoneMirror v1.5.4

v1.5.4 是一次窗口外观与缩放交互修复版本，重点处理右下角缩放手柄和驱动管理器浅色模式的背景层级，不改变 USB、AirPlay、解码、音频或驱动安装协议。

## 窗口缩放外观

- 移除主窗口右下角的点阵缩放三角。
- 移除关于、画面设置、媒体输出、投屏设置、启动错误和更新窗口右下角的缩放手柄。
- 移除驱动管理器及其可缩放窗口的右下角缩放手柄。
- 保留窗口边缘和四角的拖拽缩放能力，窗口尺寸和最小尺寸限制不变。
- 新增全窗口静态回归检查，防止后续窗口重新使用 `CanResizeWithGrip`。

## 驱动管理器浅色模式

- 将驱动管理器窗口从半透明 `AppBackgroundBrush` 切换为不透明的 `WindowBackgroundBrush`。
- 修复浅色模式下窗口外层出现中灰色、与中央白色工作区反差过重的问题。
- 驱动管理器子窗口在主题切换后也继续使用不透明背景，不会重新退回灰色半透明效果。
- 保持深色模式的深色背景、Mica/DWM 圆角、标题栏控件和卡片层级。

## 兼容性与升级

- 继续支持 Windows 10/11 x64。
- 安装包和便携版仍为自包含发布，不要求目标电脑单独安装 .NET。
- 本次没有修改 USB Screen Capture、AirPlay、QuickTime、音频、OBS 输出、虚拟摄像头或驱动安装逻辑。
- 没有新增第三方运行时依赖，也没有修改用户设置文件格式。
- 覆盖安装会保留 `%LOCALAPPDATA%\iPhoneMirror` 中的主题、语言、更新选项和设备设置。
