当前主程序和驱动管理器版本：1.8.5-pre；程序集和文件版本：1.8.5.0；根 CMake 版本仍为 1.8.4。包含 1.8.4-test4、后续开发及 1.8.5-pre 预发布准备。基线 1.8.3 自身的 libusb0.dll 升级修复不重复计入。

## 1. 键盘映射与分步骤向导

- 新增投屏设置中的键盘映射管理入口，默认关闭且没有默认绑定。
- 按物理扫描码和扩展标志绑定按键，切换键盘布局后仍对应原物理位置。
- 支持数字、小键盘、方向、导航、空格、回车、Tab、Esc、功能键及左右修饰键等按键族。
- 支持点击、固定时长长按、按住直到松开、双击和滑动；滑动可按方向配置或拖动录制。
- 按住直到松开在按下时建立触点，松开时释放；固定时长长按保持独立语义。
- 新增录入按键、选择动作、参数设置、预览取点/录制、确认保存的分步骤向导。
- 不需要参数的操作自动跳过参数页；编辑已有映射预载按键、操作、参数及位置。
- 上一步及返回已完成步骤保留草稿；支持 Enter、Esc、Alt+左/右导航。
- 按键录入在 KeyUp 确认，录入期间 Enter/Esc 仍可作为映射键，支持停止及重新录入。
- 重复按键和快捷键冲突即时反馈，可重新录入、明确替换或编辑原映射。
- 每条映射可独立开关、编辑、删除；列表更改自动保存，编辑在确认页完成后保存。
- 保存失败保留草稿；损坏、重复、非法参数及未知版本受到校验，不重置其他设置。
- 取点/录制时隐藏管理和编辑窗口，直接在原投屏画面操作，结束后恢复。
- 去除视频黑边并复用方向/反转转换，保存归一化坐标，标记随缩放和方向重新投影。
- 主预览及独立预览显示按键标记；普通标记穿透鼠标，仅取点模式接收鼠标。
- 滑动起终点必须在画面内且不同；持续时间及双击间隔有范围校验。
- 设备、会话、方向或尺寸变化取消取点，确认页提示返回重取，并保留其他参数。
- 草稿有修改时，取消、父窗口关闭及应用退出先确认放弃，继续编辑可撤销关闭。
- 编辑、取点、文本输入、弹窗、老板键隐藏或未知焦点时暂停映射。
- 自动连发不重复执行，同一映射未结束不重入，超限不会积累动作队列。
- 可选阻止已映射普通键的 Windows 行为，默认不阻止，无可用目标时不拦截。
- 单独修饰键与组合键分别处理；左右 Win 可分别绑定，系统组合保留 Windows 回退。
- 软件注入键不触发映射；绝对坐标映射用于 USB/无线，蓝牙显示能力说明。

参考：[映射](../KEYBOARD_MAPPING.md)、[向导](../KEYBOARD_MAPPING_WIZARD.md)、[修复记录](../KEYBOARD_MAPPING_REPAIR.md)。

## 2. 统一键盘路由与快捷键

- 统一 Router 仲裁快捷键、映射、普通设备输入和 Windows 输入，复用唯一低级键盘 Hook。
- Hook 有效时 WPF、原生窗口、Raw Keyboard 不再重复发送；回退入口也使用同一 Router。
- 首次 Down 固定归属，重复与 Up 沿用同一归属，避免一次输入多次执行或跨模式释放。
- 优先级统一为录入事务、精确匹配快捷键、映射、普通输入/Windows 回退。
- 按完整修饰键掩码匹配，Ctrl+Shift+F1 不误触发 Ctrl+F1。
- 完整消费快捷键组合，避免 Ctrl/Shift 前缀先泄漏到手机。
- 映射模式也支持设备快捷键及复制粘贴，未映射普通键按模式回退。
- RegisterHotKey 用于保存时检查外部占用，WM_HOTKEY 不再重复执行业务动作。
- 独立窗口 F11/Escape 由统一路由定位当前预览；Escape 优先退出全屏。
- 鼠标快捷键读取 Router 修饰键状态，避免 WPF 缺少暂存候选键。
- 模式切换先撤销旧许可、取消手势、排空发送、释放旧后端，再开放新归属。
- 切换时仍按住的旧键隔离至 Up，迟到重复及释放不进入新设备/新模式。
- 发送捕获设备、传输、会话、代次，取得写锁后再次校验；清理只针对原会话。
- 失焦、关闭、设备/会话切换及重连时释放旧按键和触点，取消过期队列。
- 快速短按即使在 UI 队列启动前结束，也保留完整 Down/Up 顺序。
- 修复原生预览点击不取得键盘焦点；鼠标焦点检查不再借用编辑控件的键盘门控。
- Windows 候选回放保持 Down/Up 顺序；组合回退不让原始 Up 超过延迟 Down。
- 修复快捷键设置 Tab/Shift+Tab 导航、Escape 关闭及保存失败完整回滚。

参考：[统一路由](../KEYBOARD_INPUT_ROUTER.md)、[输入所有权](../KEYBOARD_INPUT_OWNERSHIP_REVIEW.md)。

## 3. 五点触控

- USB/无线共用五点触控，主预览、独立预览及全屏支持触摸事件。
- 同设备最多五个不同映射并发，鼠标、滚轮、触摸屏和映射共享额度。
- 各触点具有独立 ID、来源窗口及控制会话，移动分别合并、抬起独立释放。
- 第六点被拒绝，不挤掉已有点；空位出现后必须重新 Down，旧 move 不自动占位。
- 修复旧 slot 位编码碰撞及单点报告使其他手指被抬起的问题。
- 每批发送完整活动/释放接触报告，发送成功后才回收 slot。
- 过滤触摸兼容鼠标消息，避免首指重复点击；移出预览按最后有效位置释放。
- 失焦、关闭、方向变化、设备切换及恢复时清理，旧会话不能向新桥发送输入。
- 新增 Safari 原生 TouchEvent 观察页和 USB/无线真机测试入口。
- 历史 iPhone 12 mini/iOS 18.7.8 记录覆盖五点保持、单点移动、独立抬起、超限、复用及取消释放。
- 应用需搭配当前源码桥接器；冻结 EXE 自检新增多触点独立释放检查。

参考：[五点触控](../FIVE_POINT_TOUCH.md)。蓝牙相对鼠标不支持五点绝对触控；实体 Windows 五指触摸屏仍有独立验收边界。

## 4. 多设备、身份绑定与焦点隔离

- USB/无线控制改为每设备独立会话，可保留多台连接，输入随当前预览焦点切换。
- 独立窗口焦点不改变主界面设备选择；单台慢写入不阻塞其他设备键盘发送。
- 后台设备迟到清理不清除前台输入；停止/恢复/取消仅影响对应设备。
- 蓝牙启动快捷键指向获得焦点的预览设备；多 USB/无线连接可与一条蓝牙连接共存。
- 同一物理设备的不同投屏别名禁止重复占桥，异步操作和进度/重试保存原目标。
- 键盘只发送至拥有对应路由的前台窗口；外部程序、弹窗及最小化暂停输入。
- 失焦释放原设备按键，重新聚焦不补发过期队列。
- 未绑定控制入口可打开状态窗口，首先 CheckingBinding，显示具体绑定要求及操作指引。
- 检查失败不初始化 DDI/HID/桥接；各入口复用同一身份解析和档案校验。
- 不按名称猜测目标，保存绑定快照并在确认、握手、桥接返回和恢复阶段复查。
- 绑定变化不会自动控制另一台设备；AirPlay 型号占位值归一化为未知，真实不同型号仍拒绝。
- 修复旧桥回调干扰新控制会话、模式切换重入及状态不一致。

参考：[多设备](../MULTI_DEVICE_CONTROL.md)、[绑定检查](../CONTROL_BINDING_VALIDATION.md)。

## 5. 双向文本剪贴板

- 增加/完善 USB/无线手机文本读取、Windows 写入及 Ctrl+C/Ctrl+V 流程，映射模式也可使用。
- Ctrl+C 发送完整 Command+C 并主动读取，重复手机文本也能覆盖较新的 Windows 复制。
- 普通 C/V 仍可映射，本地 Windows 编辑控件保持自身复制粘贴。
- 轮询与前台写入独立且有界，避免锁屏/服务唤醒/繁忙剪贴板卡住 HID 输入。
- 调整 PULL/SET 锁等待预算，前台粘贴不因慢轮询先耗尽等待。
- 手机回传跟随最后选中的控制设备，失焦后仍后台同步；其他设备更新按设备缓存。
- 用 Windows 剪贴板序列版本保护请求和回传，迟到手机内容不覆盖用户新复制。
- 空/非文本取消旧重试但不清空 Windows 内容，处理 A→空→A 的去重恢复。
- Windows 剪贴板繁忙时 STA 分阶段重试，旧桥回复按来源/会话过滤。
- 完善 UTF-16 和 Unicode 解析，覆盖中文及重音字符。
- 按序列化字节检查 4 MiB 帧上限，超长粘贴在写头前拒绝，保留桥连接。
- 模式交接取消旧异步粘贴，在原会话释放键盘状态。

参考：[Router 剪贴板续审](../KEYBOARD_INPUT_ROUTER.md)、ClipboardSyncState、MainWindow.ClipboardShortcuts。iOS 粘贴许可及目标应用行为仍影响实际结果。

## 6. USB/无线反控、DDI 与恢复

- 新增分阶段反控状态窗口，覆盖绑定、连接、服务、DDI、路由、就绪、恢复及失败，支持取消/重试。
- 修复成功倒计时被旧 Connecting 状态取消，导致停在 1 秒或不自动关闭。
- 倒计时由 UI 状态统一管理，零秒进入完成路径并关闭实际窗口；错误/替换窗口撤销旧回调。
- 新增较旧 iOS 配对路径 RemotePairing 回退，实际支持仍需 CoreDevice/HID 能力验证。
- 完善 DDI 本地镜像、环境覆盖、GitHub/代理/镜像下载候选、校验、挂载及服务表刷新。
- 纳入个性化 DDI 资源/清单/信任缓存；下载测速排序和各阶段错误更明确。
- 锁屏、密码、未信任和查询失败不再误报开发者模式关闭，增加旧协议不支持前置提示。
- 9021 认证兼容分支尝试实际可用的直接 HID，未验证不报告 Ready。
- USB/无线启动和恢复核验实际传输，避免切 USB 后仍显示无线就绪。
- Apple USB 服务不可用不再无条件阻断独立无线发现，空闲无线断联更新恢复状态并关闭输入闸门。
- 单一恢复所有者优先刷新 HID，再按需重建 CoreDevice/RSD；观察底层 EOF/正常返回/异常结束。
- 健康检查改为每 0.5 秒小 PING，首次恢复立即执行，死亡传输跳过无效 HID 重试。
- 保留有界重试/退避，释放旧输入并通过同连接应答验证后开放发送。
- 保留健康 mux，死读取器重开句柄/监听器，不复用失效客户端。
- 有线→无线→有线交接活动投屏生命周期内 mux 序号/源端口，避免第二次 VERSION 无回应。
- 快照在清理结束后生成，限同设备/生命周期、内存保存、单次消费并校验 USB 身份/配置。
- 恢复候选须经 Lockdown/HID 验证，失败丢弃并尝试一次新握手；停止拒绝迟到 Ready。
- 保持恢复期间唯一 stdin 帧读取器，避免取消线程读取后两个读取器竞争。
- USB 捕获停止/设置重启前清理同物理设备反控，包括 AirPlay 别名会话。
- 视频静默但音频持续时避免不必要协议重置；保留终态 USB 配置恢复警告。

参考：[恢复](../WIRED_RECOVERY_FIX.md)、[复审](../WIRED_RECOVERY_REAUDIT.md)、[延迟](../WIRED_RECOVERY_LATENCY.md)、[倒计时](../WIRED_CONTROL_COUNTDOWN_FIX.md)。mux 重建历史实测仍可能约 17 秒。

## 14. 性能、协议与安全

- 帧交接三缓冲替代每帧 ToArray，GPU 读回复用 staging texture，格式/尺寸/设备失效重建。
- RAII 确保 Unmap/keyed-mutex 释放；QuickTime 完整包直接读取，组包仅保留未完成部分。
- HID/剪贴板直接 UTF-8 序列化，H.264 转换复用线程缓冲并验证长度/截断/极值。
- Plist XML 限制 128 层递归，socket 拒绝非正超时，USB 发现信号量配对和异常清理。
- 捕获/停止/原生日志 noexcept 防止异常逃逸，无线宿主共享参数/能力/IPC 辅助。
- USB bridge 序列生成加锁，严格匹配目标 UDID，清理只释放自身接口/监听器。
- 驱动、更新和虚拟摄像头提权隔离继承环境、模块/路径及运行时变量。
- 受保护目录暂存并 SHA-256 验证载荷，固定权限和拥有者，驱动保持独立自包含。
- 安装后经交互桌面 Shell 普通权限重启主程序，避免继承管理员令牌。
- 增加帧大小、载荷、解压及目标身份安全回归。

历史微基准：1080p NV12 120 帧交接预热后分配从约 373 MB 降为该路径零分配；完整 64 KiB QuickTime 包解包耗时下降约 48.8%。不代表整应用零分配或端到端 FPS 收益。参考：[性能](../PERFORMANCE-AUDIT.md)。
