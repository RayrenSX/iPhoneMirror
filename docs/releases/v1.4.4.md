# iPhoneMirror v1.4.4

本版本重点修复 Apple Mobile Device Service 在部分 Windows 10/11 电脑上无法准备完成的问题，并强化驱动变更后的设备信任确认与投屏握手超时提示。

## Apple Mobile Device Service 安装修复

此前，Microsoft Store 版 Apple Devices 可能已经提供 `appleusb.inf`，但传统的 `Apple Mobile Device Service` 并未注册。旧逻辑会继续等待约三分钟并重复记录状态，随后才下载 Apple 官方兼容包，容易让用户误认为安装器卡死或安装失败。

v1.4.4 调整为按驱动和服务的实际状态选择路径：

- Apple USB INF 已存在、服务缺失时，不再重复安装 Microsoft Store 版 Apple Devices，直接进入服务兼容组件安装。
- Apple USB INF 缺失时，仍优先通过固定 Store 产品 ID `9NP83LWLPZ9K` 安装 Apple Devices。
- Store 安装完成后只进行短时验证；如果只获得 INF 而没有服务，会立即进入兼容组件路径。
- 已注册但停止的 Apple Mobile Device Service 会优先尝试启动，不再无条件重装。
- 状态轮询改为一秒一次，并只写入开始、可恢复、成功或超时摘要，避免产生数百行重复日志。

## 只安装必要的 Apple 组件

兼容路径不再静默安装完整桌面版 iTunes：

1. 从 Apple 官方 HTTPS 地址下载已签名的安装包。
2. 在普通用户权限下执行 Apple 官方 `/extract` 提取流程。
3. 只选择 `AppleMobileDeviceSupport64.msi`。
4. 验证 EXE 与 MSI 的 Windows Authenticode 签名主体必须为 Apple Inc.
5. 计算 SHA256，并在提权执行前再次锁定文件、验证签名和哈希。
6. 仅通过 `msiexec` 安装 Apple Mobile Device Support，不安装完整 iTunes 应用。
7. 安装后验证 Apple USB INF、服务注册和服务运行状态；必要时尝试启动服务。

官方兼容包下载现在显示百分比、已下载大小和总大小。用户取消 UAC 后会立即停止，不再继续下载或重复弹出授权。Windows Installer 返回 `1641` 或 `3010` 时，会明确提示重启电脑完成驱动和服务注册。

> 公共 Release 不包含、也不重新分发 Apple 专有 MSI、INF 或驱动二进制文件。缺失的 Apple 组件始终从 Microsoft Store 或 Apple 官方 HTTPS 渠道获取。持有 Apple 再分发授权的构建者仍可使用项目已有的授权离线 MSI 构建参数。

## 驱动变更后的设备信任确认

以下操作成功改变驱动状态后，驱动管理器会要求用户检查 iPhone/iPad 屏幕：

- 安装 Apple USB 支持；
- 一键安装全部驱动；
- 修复错误的 Apple USB 父驱动绑定；
- 安装或修复当前设备的 libusb0 采集过滤驱动；
- 卸载当前设备的采集过滤驱动。

确认窗口提供三个明确选项：

- “出现了提示，我已点击信任”；
- “没有出现提示（此前已信任此电脑）”；
- “尚未处理”。

用户选择“尚未处理”时，驱动管理器会保留待处理状态，并将选择写入结构化日志。设备密码只应输入在 iPhone/iPad 上，iPhoneMirror 不会要求或保存设备密码。

## 投屏 no-PING 超时提示强化

当设备已连接但长时间没有响应投屏握手（日志包含 `sent no PING`）时，不再使用普通小字号错误正文，而是显示专用恢复窗口：

- **重启 iPhone 或 iPad**；
- **更换 Apple 原装或 MFi 认证数据线**。

这两项操作使用大字号、半粗体和高对比警示区域显示，并单独提醒重新连接和投屏时保持设备解锁。普通投屏错误仍使用原有错误窗口，不受影响。

## 日志与诊断

- 驱动管理器主日志：`%LOCALAPPDATA%\iPhoneMirror.Driver\Logs\driver-ui.log`
- Apple MSI 详细日志：`%LOCALAPPDATA%\iPhoneMirror.Driver\Packages\apple-support-install.log`
- 驱动变更后的信任选择会记录为 `device_trust_response` 事件。
- AMDS 提取、签名验证、下载、MSI 返回码、服务恢复和重启要求均有独立事件。
- 主程序“清理日志和更新缓存”现在也会清理 Apple MSI 安装日志。

## 其他修复

- 修正原生核心 DLL 数字型文件版本仍停留在 `1.4.1.0` 的问题；v1.4.4 的托管程序集、原生资源、安装器和发布脚本版本保持一致。
- FFmpeg 构建依赖下载遇到超时、限流或服务器临时错误时会按 5、15、30 秒间隔重试，避免第三方下载源短暂返回 HTTP 503 导致整个发布构建失败；每次失败都会清理未完成文件，固定 SHA256 校验保持不变。
- 更新中英文资源，并增加 UI 回归测试，确保 no-PING 窗口中的两条关键建议保持至少 18px 且使用半粗体。
- 更新 Apple 驱动依赖文档和未发布变更记录。

## 已知提示

- 当前公开安装程序尚未使用商业代码签名证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从本项目官方 GitHub Release 下载，并使用 `SHA256SUMS.txt` 校验完整性。
- 安装 Apple Mobile Device Support 后，如果 Windows 要求重启，请重启电脑再重新检测驱动。
- 驱动安装完成但设备没有出现信任提示时，通常表示该电脑此前已经被设备信任；仍需保持设备解锁后重试投屏。
