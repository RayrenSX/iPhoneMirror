# iPhoneMirror v1.6.3

v1.6.3 是一次以更新可靠性和边界安全为重点的维护版本。它让应用内更新窗口能够
展示完整发布说明，同时加固安装版与便携版从“下载完成”到“提权执行”的整个链路。
媒体输出、解码器、虚拟摄像头和 Apple 设备信息读取中的异常输入与资源回收也得到
针对性修复。

## 更新体验

- 更新窗口现在显示正式 Release 名称，并从对应版本标签读取完整发布文档，不再只
  展示 GitHub API 或备用更新清单中的摘要。
- 新增“打开发布页面”入口，只允许跳转到本仓库受信任的 GitHub Release 地址；完整
  发布文档暂时不可用时，仍会保留 API 返回的说明作为回退。
- 发布列表、发布说明和 `SHA256SUMS.txt` 改为流式读取并分别限制最大长度，避免未知
  `Content-Length` 的异常响应占用无界内存。
- 预发布版本比较不再把数字标识转换为固定宽度整数，因此超长数字标识也能按
  Semantic Versioning 规则稳定排序。
- 单实例冲突检测现在同时校验会话、进程名和可执行文件完整路径，不会把其他目录中
  同名的 `iPhoneMirror.exe` 当作当前安装的实例。

## 安装版更新完整性

- 下载完成后的 SHA-256 校验结果会一直传递到启动阶段；提权前再次锁定并校验安装包，
  防止校验完成后文件被替换。
- 提权后的引导程序会再次核对安装包哈希，将其复制到仅 Administrators 与 SYSTEM
  可完全控制的 `ProgramData` 临时目录，再从该副本启动 Setup。
- 安装程序退出后清理受保护的临时副本；哈希不匹配、提权失败或启动失败时不会执行
  未验证文件。

## 便携版更新与回滚

- ZIP 更新辅助脚本改为程序集内嵌资源。启动时写入独立临时目录，并在提权环境中先
  校验脚本哈希，再通过结构化参数调用，减少脚本或命令行被篡改的窗口。
- 更新 ZIP 在整个验证和解压期间保持打开，并在执行边界再次核对 SHA-256；下载后的
  文件发生变化时立即终止更新。
- 拒绝绝对路径、盘符路径、目录穿越、重解析点以及文件/目录类型冲突，确保内容只会
  写入目标安装目录。
- 对压缩包大小、条目数量、单文件大小、总展开大小、压缩比和临时磁盘剩余空间设置
  明确上限，并在流式解压过程中再次检查实际字节数。
- 更新前为所有将覆盖或删除的文件创建备份，复制后逐文件校验哈希；任一步骤失败时
  按反向顺序恢复原文件并删除本次新建内容。
- 如果回滚本身未能完整完成，会保留恢复目录并在错误中报告位置，避免清理掉仍可用于
  手动恢复的数据。
- 只会关闭并在必要时终止目标安装目录中的主程序和驱动管理器；旧版残留的 FFmpeg
  文件仍按便携版覆盖更新规则安全移除。

## 媒体、虚拟摄像头与设备信息

- FFmpeg 在进程创建、启动或音频管道连接的任一阶段失败时，都会清理已创建的进程、
  命名管道和录制临时文件，避免失败重试留下句柄或不完整录像。
- Media Foundation 解码器在转换器拒绝输入但又不产生输出时明确失败，避免无进展的
  解码循环。
- 虚拟摄像头会校验管道和注册表字符串的字节对齐、长度与终止符，并限制帧尺寸及
  采样大小计算，拒绝截断字符串和整数溢出。
- 虚拟摄像头 COM 导出使用标准 Windows ABI 声明，并增加组件级回归测试。
- 驱动管理器读取 Apple 设备名称、型号和系统版本时，对连接、发送和接收设置短超时，
  并确保超时连接被确定释放。

## 验证与兼容性

- 支持从 `v1.6.2` 安装版直接覆盖升级，也支持便携版应用内更新；用户设置、录制目录
  和驱动配置保持不变。
- Release 构建继续面向 Windows 10/11 x64，同时包含 USB 与 AirPlay 投屏、音频、
  录制/推流、虚拟摄像头和独立驱动管理器。
- 自动化覆盖完整发布构建、原生 CTest、应用逻辑测试、WPF 运行时测试、驱动管理器
  测试、ZIP 成功更新、哈希篡改、路径穿越、压缩比限制、失败回滚和虚拟摄像头边界。

### Changed

- Display the full tag-specific release document, release title, and a trusted
  link to the GitHub Release page in the updater.
- Stream release metadata, detailed notes, and checksum manifests through
  explicit response-size limits while retaining metadata notes as a fallback.
- Compare arbitrarily large numeric prerelease identifiers according to
  Semantic Versioning without fixed-width integer conversion.

### Fixed

- Revalidate downloaded Setup and ZIP packages across the elevation boundary,
  and execute only verified copies or embedded helpers from access-controlled
  staging directories.
- Make portable ZIP updates transactional with archive limits, path and
  reparse-point validation, post-copy hashes, reverse-order rollback, and
  preserved recovery data when rollback cannot finish.
- Restrict update-cache traversal and single-instance process matching to the
  intended directory and executable path.
- Release FFmpeg processes, audio pipes, and recording staging files after
  partial media-output startup failures.
- Fail stalled Media Foundation decoder input explicitly.
- Validate virtual-camera pipe and registry strings, frame dimensions, sample
  sizes, bitrates, and COM exports before accepting them.
- Dispose Apple device metadata connections deterministically after connect or
  I/O timeouts.

### Security

- Bound every updater-controlled text and checksum response even when the
  server omits `Content-Length`.
- Reject ZIP traversal, reparse-point targets, excessive expansion, extreme
  compression ratios, and packages that would exhaust temporary storage.
- Carry the verified SHA-256 digest through launch and verify package or helper
  bytes again immediately before elevated execution.
