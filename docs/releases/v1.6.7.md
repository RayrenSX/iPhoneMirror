# iPhoneMirror v1.6.7

v1.6.7 修复了应用内更新下载完成后显示蓝色 Windows PowerShell 窗口的问题。

## 更新体验

- 安装版 Setup 更新和便携版 ZIP 更新现在共用同一套隐藏窗口启动配置。
- 同时向 Windows 进程启动器和 Windows PowerShell 显式请求隐藏控制台，避免蓝色窗口遮挡应用界面。
- 安全校验、管理员权限和自动重启流程保持不变。Windows UAC 确认仍会在需要时正常显示。
- 新增回归测试，同时验证 Shell 提权、Win32 隐藏窗口设置和 PowerShell `-WindowStyle Hidden` 参数。

### Fixed

- Hide the elevated PowerShell host used to verify and apply installer and
  portable ZIP updates while preserving the required UAC prompt.
