# iPhone Mirror 1.8.5-pre 完整更新说明

日期：2026.10.06
版本类型：预发布测试版

iPhone Mirror 已更新至 1.8.5-pre。本页汇总自 1.8.3 以来的更新，包含此前 1.8.4 测试阶段的功能、优化与修复，以及 1.8.5-pre 的新增内容；相同主题合并展示。

## 键盘映射与快捷键

- **新增** 键盘映射功能，支持点击、固定时长长按、双击、滑动及按住直到松开，可独立启用、编辑和删除映射。
- **新增** 分步骤键盘映射向导，支持按键录入、动作选择、参数设置、投屏取点、滑动录制及确认保存。
- **新增** 数字、小键盘、方向、导航、功能键及左右修饰键等按键类型支持，按物理按键位置保存映射。
- **新增** 主预览和独立预览中的映射标记，随画面旋转与缩放自动重新定位。
- **新增** 统一键盘输入路由，协调快捷键、键盘映射、设备输入及 Windows 输入，减少重复触发和输入冲突。
- **优化** 快捷键精确匹配、重复映射提示和冲突处理，避免组合键前缀泄漏到设备。
- **优化** 键盘输入所有权，确保按下、重复和释放始终归属于同一设备与控制会话，切换后丢弃过期输入。
- **修复** 全屏预览中的 Escape 被反向控制键盘路由截获的问题，优先用于退出全屏。
- **修复** 快捷键设置保存失败时部分覆盖原设置的问题，失败后恢复完整设置快照，并改善设置窗口的键盘导航。

## 五点触控、鼠标与输入释放

- **新增** USB 与无线反向控制五点触控，可同时管理最多五个独立触点，支持主预览、独立预览及全屏操作。
- **优化** 多触点独立移动、抬起、释放及超限处理，避免不同手指互相影响，防止旧触点在新会话中继续生效。
- **新增** 原生光标恢复与绝对鼠标输入处理，改善远程鼠标定位及设备分辨率变化后的坐标处理。
- **优化** 高速鼠标事件合并与队列管理，限制积压，并在失败、停止和重连后清理旧输入。
- **修复** 绝对鼠标坐标被误当作相对位移，导致 iPhone 光标跳至右下角的问题。
- **修复** 鼠标移出镜像预览后 USB 触控未释放的问题，按最后有效位置释放触点，避免拖拽和按键残留。
- **修复** 设备切换、窗口失焦、关闭预览、控制模式切换和重连时未正确释放键盘、鼠标、滚轮及触控状态的问题。

## 多设备与控制会话

- **新增** 多设备独立控制会话，可同时保持多台 iPhone/iPad 的有线或无线反向控制连接，分别管理启动、停止、恢复、状态及进度。
- **新增** 主窗口与独立预览窗口的焦点输入路由，输入随当前预览焦点切换，切换时释放旧设备状态。
- **优化** 设备身份绑定与控制目标校验，确保触控和键盘输入始终发送到当前选中或获得焦点的设备。
- **优化** 多设备并发输入，避免单台设备写入停滞阻塞其他设备，后台会话清理不再影响前台设备。
- **优化** 控制模式切换期间的互斥处理，避免同一目标的有线、无线与蓝牙控制相互争抢输入。
- **修复** 旧桥接器回调、旧任务及迟到恢复结果影响新控制会话的问题，防止切换或重连后状态被覆盖。
- **优化** 蓝牙设备绑定、控制路由及多窗口设备选择，减少目标识别歧义和误发送。

## 双向文本剪贴板

- **新增** Windows 与 iOS 双向文本剪贴板同步，支持复制、粘贴及按设备保存剪贴板状态。
- **新增** 剪贴板同步状态管理、控制状态服务及单飞操作保护，避免重复操作同时执行。
- **优化** 剪贴板并发、请求时序及序列号校验，避免迟到的手机内容覆盖 Windows 上刚复制的新内容。
- **优化** 剪贴板忙碌、锁屏、服务唤醒及控制模式切换时的等待、重试与取消处理，减少对键鼠输入的影响。
- **优化** Unicode、UTF-16、超长文本和繁忙状态处理，提升中文等复杂文本输入的稳定性。

## 有线与无线反向控制、DDI 和恢复

- **新增** 分阶段反向控制状态窗口，展示设备绑定、连接、DDI、服务、路由、就绪、恢复及失败状态，支持取消和重试。
- **优化** 状态窗口资源、状态色及中英文、简繁中文显示，完善成功倒计时及完成后自动关闭行为。
- **新增** 有线反向控制恢复、设备自动化与驱动安全验证工具。
- **优化** USB 桥接、锁定握手、断线检测、健康检查和自动恢复，完善有线与无线之间的交接及恢复后的输入释放。
- **新增** 旧版 iOS 的 RemotePairing 回退路径，提高旧系统的配对兼容性。
- **新增** DDI 回退资源包及对应运行时准备机制，完善本地镜像、环境配置覆盖、GitHub 镜像下载、测速、校验、挂载及服务准备流程。
- **优化** DDI 下载和缓存安全，支持完整性校验、原子替换及分阶段错误说明。
- **优化** USB、无线与蓝牙控制的提示、失败诊断、重试、取消及状态清理，提供更明确的错误代码和处理指引。

## 蓝牙输入稳定性

- **优化** 蓝牙鼠标和键盘的有界队列、发送超时、代次隔离及故障恢复，避免高速输入积压和旧任务污染新会话。
- **修复** 蓝牙通知阻塞导致鼠标卡住、按键残留，以及停止后队列残留的问题。
- **修复** 蓝牙发送超时、旧任务恢复及重连后输入泄漏的问题，失败后及时清理失效任务并恢复本机光标状态。
- **新增** 蓝牙 HID 压力工具，用于验证长时间高负载输入场景下的稳定性。

## 无线画面、UxPlay 与媒体输出

- **优化** 无线投屏横竖屏切换、静态画面保留及重绘，减少画面停滞和闪烁，并支持调整窗口后复用最后一帧。
- **新增** UxPlay 独立可选组件，支持按需下载安装、进度显示、取消重试及离线准备。
- **优化** UxPlay 的版本发现、依赖清单、下载、缓存、校验、安装及回滚流程，完善运行时和发布打包。
- **修复** UxPlay 自动测试版本生成错误下载地址而出现 404 的问题，完善组件资产校验与失败信息。
- **优化** HLS、AirPlay、DNS-SD、多网卡发现及媒体输出稳定性，改善播放连接和长时间运行时的资源回收。
- **修复** DNS-SD 注册、AirPlay/UxPlay 运行时发现及部分媒体工作流的稳定性问题。

## 录制、直播与虚拟摄像头

- **新增** 直播推流麦克风选择、设备刷新及与手机音频混音，麦克风默认关闭。
- **优化** 录制补帧、音视频时间轴同步及停止后的保存反馈。
- **修复** 录制补帧达到上限时错误推进视频时间轴，导致视频与音频时长不一致的问题。
- **优化** 虚拟摄像头启动、停止、帧交换及生命周期管理，避免旧实例或迟到停止操作关闭新实例。
- **修复** 录制、媒体播放、虚拟摄像头及网络媒体工作流中的多项资源释放和并发稳定性问题。
- **优化** HLS 播放、媒体输出、录制、虚拟摄像头及 D3D11 预览渲染链路。

## 托盘、紧凑启动与界面

- **新增** 托盘模式、托盘图标、设备面板及独立预览，可在轻量模式下快速控制指定设备。
- **新增** `--compact --device <UDID>` 紧凑启动方式，支持直接启动指定设备，并通过命名管道打开或激活对应独立预览。
- **新增** 从投屏设置创建绑定设备的桌面快捷方式，完善窗口样式设置与圆角窗口基础控件。
- **优化** 主窗口、独立预览、托盘、圆角窗口及 DPI/尺寸变化处理，减少捕获竞争和布局跳动。
- **修复** 主窗口和独立窗口反复调整圆角区域时重复创建区域、拖动捕获相互干扰的问题。
- **优化** 工具栏空间不足时从右向左收起文字、保留图标，空间恢复后自动显示文字，并保留提示与无障碍名称。
- **优化** 大字体、小窗口、高对比度和键盘操作支持，改善对话框、设置页面与媒体控件的可访问性。
- **修复** 从托盘首次打开工作区时图标颜色不同步，以及主预览有线、无线触控未正确初始化的问题。

## 本地化与驱动工具

- **新增** 独立的繁體中文（台灣）本地化，覆盖应用、驱动工具、安装器、诊断页面及更新说明。
- **优化** 简体中文、繁体中文和英文资源，支持运行中的窗口动态刷新语言，并完善安装器和驱动信任提示。
- **新增** 父驱动管理工具，支持设备绑定、驱动变更、设备重建及回滚保护。
- **修复** 驱动父设备实例名无法识别完整 40 位 UDID 的问题，同时保留 PID、子接口和目标设备范围限制。
- **优化** 驱动操作安全验证和失败恢复，限制目标设备范围，避免影响其他 Apple 设备及共享驱动包。

## 性能、运行时、安装与发布

- **优化** GPU 帧交接、QuickTime 数据处理、H.264 转换及输入事件处理，降低运行时额外开销。
- **新增** USB 桥接器源码构建配方、许可证、依赖清单及自动化构建脚本。
- **优化** USB Bridge 运行时构建与发布，统一依赖清单、版本元数据及最终程序自检。
- **优化** 安装器、驱动清理、USB Bridge、DDI、FFmpeg 和 UxPlay 的运行时完整性检查。
- **修复** USB 桥接构建、运行时依赖、DDI 回退及发布打包完整性相关问题。
- **修复** 安装测试中过早检查 Inno Setup 卸载器清理结果的问题。
- **优化** 发布包校验，覆盖文件大小、SHA-256、SBOM、更新清单及运行时资产一致性。
- **优化** GitHub Actions 构建环境及 Windows PowerShell 兼容性，完善 Windows、.NET、Python、CMake、MSYS2 和 USB 运行时检测。
- **优化** 发布清单，补充 v1.8.3 记录并加强版本资产与更新信息同步。
