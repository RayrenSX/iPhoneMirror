# iPhoneMirror v1.5.3

v1.5.3 改进了主界面的工作区布局与左侧导航字体。投屏来源和投屏设置现在可以同时保持打开，在选择设备、调整 USB 或 AirPlay 参数时无需反复关闭和切换面板。

## 工作区多面板显示

- “投屏设置”改为独立的右侧面板，可以与“投屏来源”同时显示。
- “投屏设置”也可以与“投屏”操作面板同时显示。
- 左侧“投屏”和“投屏来源”仍保持二选一，切换其中一个时会替换另一个，不会在左侧叠加。
- 分别关闭左侧面板或右侧设置面板时，只影响当前一侧。
- 启用全屏预览时会暂时隐藏工作面板；退出全屏后恢复进入全屏前的面板选择。

## 导航文字与字体

- 中文导航中的“设备”更名为“投屏来源”，入口含义更明确。
- 英文导航中的 “Devices” 更名为 “Sources”。
- 中文导航明确使用 `Microsoft YaHei UI`，英文导航使用 `Segoe UI`。
- 导航标签改为显式文本渲染，避免控件模板继承错误字体或字重。
- 普通导航项使用正常字重，当前选中项使用半粗体，并启用适合界面文字的显示模式与超长文本省略。

## 交互与稳定性

- 左侧工作区与右侧设置区分别维护显示状态，快速切换时不会互相关闭。
- 切换一侧面板时会立即完成另一侧尚未结束的布局动画，减少连续点击造成的宽度、透明度或可见状态残留。
- 进入全屏时会取消未完成的工作区动画，避免旧动画回调在全屏期间重新写入面板宽度或可见性。
- 退出全屏时会根据进入前保存的两个独立状态恢复左侧工作区与右侧设置区。
- 诊断日志分别记录左侧工作区切换和右侧设置面板开关，便于定位界面状态问题。

## 兼容性与升级

- 继续支持 Windows 10/11 x64。
- 安装包和便携版仍为自包含发布，不要求目标电脑单独安装 .NET。
- 本次没有修改 USB Screen Capture、AirPlay、解码、音频、OBS 输出、虚拟摄像头或驱动安装协议。
- 没有新增第三方运行时依赖，也没有修改用户设置文件格式。
- 覆盖安装会保留 `%LOCALAPPDATA%\iPhoneMirror` 中的主题、语言、更新选项和设备设置。
- 有线投屏仍需要 Apple Devices，或包含 Apple Mobile Device Support 的桌面版 iTunes。

## 已知限制

- 工作区面板的展开状态不会跨应用重启保存；重新启动后默认显示“投屏来源”，投屏设置默认收起。
- 当前安装程序未使用商业 Authenticode 证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从项目官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- 公开发布包不包含 Apple 专有 MSI、INF 或驱动二进制文件。
- QuickTime Screen Capture 与兼容 AirPlay 实现并非 Apple 官方稳定接口，未来 iOS 更新仍可能需要适配。
