**v1.8.5-pre7 是 iPhoneMirror 1.8.5 正式推出前的最後一個預覽版本**，適用於 Windows x64。以下是自 v1.8.5-pre6 以來的主要改動。

### 投屏與裝置連接

- 新增已配對無線裝置偵測。同一部手機的有線和無線狀態會顯示於同一張裝置卡片。
- 新增實驗性 CoreDevice 無線投屏，目前只傳送畫面。需要 iOS／iPadOS 27 或以上、已綁定裝置、開發者模式及相符的開發者映像。
- USB 投屏提供建議使用的原生 AirPlay 和兼容示範模式。以往儲存的固定尺寸 C 模式會轉用原生 AirPlay。
- 支援在適用的 USB 投屏連線中讓聲音留在手機播放。電腦錄影或直播無法擷取該裝置的音訊。遊戲咪高峰兼容性仍需使用實機測試（#100）。
- 解像度、幀率和解碼器選項會自動儲存。色彩編輯和無線接收設定仍須分別儲存或套用。

### 預覽、檔案及獨立視窗

- 可在預覽中複製畫面文字、傳送檔案，或拖入 IPA 後選擇傳送或安裝。安裝需要有效簽署及裝置授權。
- 擴充 Windows 檔案總管對應，在同一位置顯示裝置允許存取的媒體、當機記錄和應用程式資料夾，並保留讀寫權限。
- 可按裝置記住上次的獨立視窗佈局、儲存預設佈局或自訂位置。可在快速鍵設定中配置視窗動作和 Windows 快速鍵規則（#91、#92、#93）。
- 修正部分圓角對話框的角落被主控視窗背景填滿的問題，並保留透明覆疊視窗的背景效果。

### 使用及兼容性

- 完整設定助手新增免費開放原始碼說明，以及可略過的作者支援頁面。
- 應用程式內的更新說明跟隨介面語言。GitHub Release 預設顯示英文正文，並附有獨立簡體中文連結。
- 使用指南補充兩種 USB 投屏模式、配對後的無線投屏、預覽工具及獨立視窗的操作步驟。實機測試範圍見各功能說明。
- 主程式及驅動程式管理員的產品版本統一為 `1.8.5-pre7`。
