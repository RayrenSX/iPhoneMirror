# iPhoneMirror v1.8.0

v1.8.0 是藍牙反向控制、獨立預覽視窗與橫向投屏恢復能力的正式穩定版本。

## 中文說明

- 加入相容 iOS 的 BLE HID 鍵盤與滑鼠反向控制，並保存靈敏度、滾輪、橫豎屏方向與軸向反轉設定。
- 完整配對指引每次程式執行時按裝置顯示一次；指引關閉或倒數結束後才接管 Windows 滑鼠。
- 獨立預覽視窗預設不置頂，且全螢幕、方向切換、主裝置切換與橫向有線畫面恢復均已穩定化。
- 安裝程式支援選擇安裝位置，媒體播放器亦改進了淺色主題對比與倍速選擇器。

## Bluetooth Reverse Control

- Windows exposes one BLE HID keyboard and mouse service with both Report and
  Boot Protocol support for broader iOS compatibility.
- Mouse sensitivity, wheel sensitivity, portrait and landscape direction, and
  axis reversal settings are saved locally and applied only after confirmation.
- Pairing guidance covers the full iPhone and Windows workflow. It appears once
  per device during each application run, and input begins only after the
  guidance is closed or its countdown completes.
- Bluetooth start/stop transitions are serialized, the toolbar state stays in
  sync with the current source, and switching the main preview cannot send
  input to a previously selected phone.

## Preview And Recovery

- Device orientation is derived from live source frames and used consistently
  by the main preview, independent preview, raw input, and manual rotation.
- Independent previews start as ordinary, non-topmost windows. Pinning remains
  available from the window menu.
- Full-screen previews use a complete black presentation surface and restore
  theme backgrounds and native rounded clipping on exit.
- A stalled landscape wired stream can attempt a bounded QuickTime reconnect
  without releasing the iPhone connection.

## Media Casting And Installation

- The media player has a compact overlay speed selector, corrected light-theme
  seek-button contrast, and a simplified preview toolbar.
- Setup now allows choosing an installation location while retaining the
  existing installation folder by default.

## Validation

- Windows x64 Release native CTest, application logic tests, runtime UI tests,
  driver installer tests, installer checks, package validation, SHA-256 asset
  generation, and SPDX SBOM generation are run by the release workflow.

### Added

- Add Bluetooth reverse control through a single BLE HID keyboard and mouse
  service, including Boot Protocol compatibility for more iOS devices.
- Add persistent Bluetooth mouse sensitivity, wheel sensitivity, separate
  portrait and landscape directions, and horizontal/vertical reversal options.
- Add complete iPhone and Windows Bluetooth pairing guidance and a clear main
  preview state for devices opened in independent windows.
- Add an installer location-selection page while preserving the previous
  iPhoneMirror installation folder by default.

### Changed

- Detect phone orientation from live source frames and apply one mouse mapping
  model to the main preview, independent windows, raw input, and manual rotation.
- Refine media-cast player controls and keep independent preview windows
  non-topmost by default.

### Fixed

- Recover a stalled landscape wired stream without releasing the iPhone.
- Prevent stale preview frames, orientation transitions, and full-screen
  light-theme edges from leaving incorrect presentation state on screen.
- Serialize Bluetooth transitions and keep the control button state synchronized
  with session, busy, and source changes.
