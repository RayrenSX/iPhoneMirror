这是 Windows x64 预览版，汇总 v1.8.5-pre5 之后的修复和新增功能。

### 投屏与视频应用播放

- 修复原始 AirPlay 视频应用投放中，短片、广告和正片交接时的完成通知、进度查询和跳转解析；自然结束保留发送端会话，避免接收端提前停止整个投放。关联 [#88](https://github.com/RayrenSX/iPhoneMirror/issues/88)。
- 改善分离音视频 HLS 的跨段时钟、分片失败重试、首帧等待和有限恢复；修复暂停、重播、Seek 与旧播放器回调之间的竞争。播放失败不会被误报成自然播完。
- 修复爱奇艺本集完成后不能接收下一集的问题。用户实测确认哔哩哔哩画面、声音和结束正常，以及爱奇艺本集完成后下一集能够打开；不同服务端、网络和机型仍可能有差异。
- 修复 UxPlay 横竖屏切换时的帧尺寸、旋转和 Y4M 输出处理，避免花屏或接收中断。关联 [#90](https://github.com/RayrenSX/iPhoneMirror/issues/90)。
- 修复无线预览会话重建后未重新绑定渲染目标导致的黑屏；用户使用 iPhone 17 在原画与 1080p 之间往返切换已通过。
- 应用设置增加显式代理选项，保存后供相关网络请求和子进程使用，并保持本机通信的正确路由。

### 反向控制、窗口与界面

- 改善主预览和独立窗口的输入接管、窗口关闭后的前景交接，以及 USB 连接恢复、外接键盘注册和启动取消处理。
- 有线／无线控制增加“手机输入法：显示／隐藏”按钮，默认显示。偏好应用到在线通道并在重连后恢复；有线和无线下的两轮切换与电脑输入均经用户实测确认。
- 修复关闭控制状态或设置窗口时主界面退到后台的问题；从独立投屏窗口发起控制时，将焦点交还正确的所属窗口。两种控制方式均经用户复测确认。
- 调整首次使用助手关闭按钮、步骤和驱动准备页对齐，优化驱动管理器卡片、设备选择与按钮布局，修复设备管理文件页的白色外框。
- 界面描述文字默认隐藏，修复部分说明未跟随设置即时隐藏的问题；优化禁用按钮底色，并移除不再使用的“清除所有蓝牙绑定数据”入口。
- 更新设备外观与机框资源，校准近期 iPhone 的圆角参数，并同步主预览、简易模式及独立窗口的裁切。部分素材拟合与保守轮廓不等于所有机型已经真机逐像素验证。

### 设备管理与文件

- 集成设备管理侧栏，提供应用查看、搜索和管理，以及文件浏览、导入、另存为和确认后删除。开发者工具保留设备信息、描述文件、日志等入口。
- 文件页支持媒体目录与支持文件共享的 App 文档目录，可用开关临时映射到 Windows 资源管理器；支持复制进出、创建文件夹、重命名和删除。
- 修复 Windows 复制文件时的属性设置步骤导致上传回滚的问题，保留文件修改时间；约 3.84 MB 中文 PPTX 的复制及打开已由用户实测确认。应用文档浏览和映射读写也已确认。
- 映射默认关闭，切换设备、断开控制或退出程序时清理。沿用 Windows WebClient 的单文件传输限制，界面会显示当前限额。
- 驱动管理器随完整交付提供；设备识别和布局已由用户复测确认。

### 验证范围与已知限制

- 发布流程运行原生、Python、应用逻辑、驱动和本地化检查，并生成安装包、便携包、独立 UxPlay 组件、SBOM 与 SHA-256 校验清单。
- 应用文档共享和媒体目录均不等同于手机“文件 → 我的 iPhone”的完整目录。仅电脑端的原生目录一致映射尚未实现，本版不宣称支持。
- #88 中接收端能力上限、实际帧尺寸与帧内内容比例是不同概念；正方形画布不自动代表视频被拉伸。原报告 iPad 的独立窗口场景仍欢迎按本版复测，不将其它机型的验证扩大为全部兼容性保证。
- 未将 BGMI 4K 麦克风场景、完整游戏映射或 macOS 支持列为本版已解决。
- 本版移除不可用的实验性 CoreDevice 原生媒体入口和录制文件重放入口；常规 USB／AirPlay 投屏及现有录像功能继续保留。

### Fixed

- Fix AirPlay video-item completion, ad/content handoff, scrub parsing, bounded HLS recovery and iQIYI next-episode notifications. Bilibili audio/video/completion and an iQIYI next-episode handoff were confirmed on a user phone. Related: #88.
- Fix UxPlay frame-size/rotation handling when switching orientation (#90), and rebind recovered wireless preview sessions to prevent a black preview.
- Add persistent proxy settings and a default-on phone keyboard visibility switch for wired/wireless control. Improve recovery and focus restoration after closing control windows.
- Improve setup and Driver Manager alignment, disabled button styling, description visibility, device corner clipping and frame assets.
- Add the integrated Device Hub and opt-in read/write Explorer mappings for media and file-sharing app Documents. Fix Windows upload property handling and retain modification times. Real-phone PPTX upload/open and app Documents mapping were confirmed.
- A complete mapping of Files → On My iPhone is not implemented. Existing Windows WebClient transfer limits remain. Hardware-specific reports and other unresolved scenarios are not presented as universally fixed.
