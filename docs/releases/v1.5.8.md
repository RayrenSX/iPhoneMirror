# iPhoneMirror v1.5.8

v1.5.8 集中改善 Windows 桌面端的日常使用体验，并补强多次启动和媒体输出启动阶段的可靠性。主界面的滚动条现在更细、更靠近右侧边缘，默认状态尽量融入 Mica/Card 画面，悬停时再平滑扩展；关于页面的浅色主题更新按钮保持白色文字。应用启动时会检测同一 Windows 会话中已经运行的 iPhoneMirror，并使用 Fluent Acrylic 对话窗口让用户明确选择保留哪个实例。

本版本保持现有 FluentWindow、NavigationView、Mica/Acrylic、现代 Card、圆角控件、Snackbar/Dialog、深浅主题和页面动画架构，不重新引入传统 WPF 默认控件外观。

## 单实例启动保护

- 使用当前 Windows 会话范围内的命名互斥锁识别支持新协议的主实例。
- 同时扫描同名、同会话进程，以兼容尚未创建命名互斥锁的旧版本。
- 通过命名关闭事件通知新版主实例退出，即使主窗口仍在加载也能接收请求。
- 检测到其他实例时显示 Fluent Acrylic 冲突窗口，不再使用传统 MessageBox。
- 左侧次要按钮“关闭其他窗口”会先请求优雅退出，并在成功取得主实例所有权后继续本次启动。
- 右侧主按钮“关闭当前窗口”更醒目，关闭本次启动且不干扰正在投屏的窗口。
- 简体中文和英文界面均提供完整标题、说明、忙碌状态和失败提示。
- 用户明确选择关闭其他实例后，程序先尝试关闭窗口；旧版本无响应时才使用有时间上限的进程树终止回退。

## 并发与进程安全

- 区分“更早启动的既有实例”和“稍后出现的竞争实例”，避免用户快速双击启动时两个窗口同时显示冲突提示。
- 关闭等待使用 `Stopwatch` 单调计时，不受系统时间调整影响。
- 进程扫描只处理当前用户会话，并及时释放被过滤的进程句柄。
- 无法读取进程状态时采用保守结果，避免错误报告“其他窗口已关闭”。
- 关闭其他实例期间暂时禁用三个关闭入口，避免后台关闭任务与应用退出同时释放协调对象。

## 现代滚动条

- 全局滚动条布局槽缩小到 6 px，默认滑块宽度或高度为 2 px。
- 鼠标悬停时滑块以缓动动画扩展到 4 px，同时淡入轻量轨道反馈。
- 浅色和深色主题分别定义轨道、默认、悬停与按下状态画刷。
- 主界面设置区域的纵向滚动条向右偏移 6 px，并为内容保留 10 px 空间。
- 滚动条靠近右侧视觉边缘，但不会覆盖设置内容或与圆角 Card 边框重叠。
- 横向和纵向滚动条继续支持分页命令、最小滑块尺寸和拖动状态。

## 浅色主题可读性

- 关于页面“检查更新”按钮在浅色模式下显式使用白色文字。
- 深色模式继续使用适合浅色强调背景的深色文字。
- 新增运行时主题断言，防止后续资源调整再次降低按钮对比度。

## 媒体输出启动可靠性

- FFmpeg 初始观察窗口结束后，程序在等待投屏音频管道连接时继续监控 FFmpeg 进程。
- 如果 FFmpeg 在音频握手阶段退出，立即报告实际启动失败，不再等待 5 秒后误报管道超时。
- GitHub Actions 中暴露该问题的计时敏感测试已替换为确定性的延迟退出进程测试。
- 修复不改变录制、RTMP、SRT、WHIP 参数、编码器选择或音视频数据格式。

## 兼容性与升级

- 支持 Windows 10 1809 及以上版本和 Windows 11 x64。
- 可直接覆盖安装 v1.5.7；主题、语言、更新选项和设备设置继续保存在 `%LOCALAPPDATA%\iPhoneMirror`。
- 不修改 USB Screen Capture、AirPlay、H.264/CoreMedia 解码、音频渲染、OBS 输出、虚拟摄像头协议或驱动安装协议。
- 没有新增第三方运行时依赖，也没有修改用户设置文件格式。
- 公开发布包不包含 Apple Mobile Device Support、iTunes 或其他 Apple 专有二进制文件。

## 已知限制

- 当前安装程序未使用商业 Authenticode 证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从项目官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- 单实例保护范围是当前 Windows 登录会话，不会尝试关闭其他用户会话中的进程。
- QuickTime Screen Capture 与兼容 AirPlay 实现并非 Apple 官方稳定接口，未来 iOS 更新仍可能需要适配。
