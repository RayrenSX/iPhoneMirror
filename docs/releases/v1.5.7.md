# iPhoneMirror v1.5.7

v1.5.7 集中修复应用运行期间的主题切换一致性，并整理主题设置的位置。现在从主界面的“应用偏好”切换浅色、深色或跟随系统时，已经打开的关于、更新、画面、投屏、媒体输出、提示等子窗口会立即采用正确配色，不再出现控件颜色与窗口背景来自不同主题的情况。本版本同时清理虚拟摄像头项目的编译警告，不修改 USB Screen Capture、AirPlay、解码、音频、OBS 输出、虚拟摄像头协议或驱动安装流程。

## 子窗口主题同步

- 主题切换不再把所有窗口统一套用为 Mica，而是逐个读取窗口自己的 `Mica`、`Acrylic` 或 `None` 背景类型。
- 已经打开的子窗口会同时刷新 WPF-UI 背景、窗口透明表面、DWM 深浅色标记、边框与圆角策略。
- 主窗口进入最大化或全屏时继续关闭系统背景并使用贴边策略；退出后恢复 Mica，不受主题切换影响。
- 主题字典现在通过 `iPhoneMirror` 应用程序集的明确资源地址加载，不再依赖当前启动宿主恰好就是主程序。
- 保留原有 180 毫秒轻量过渡动画，切换期间不会重建或关闭正在使用的子窗口。

## 设置位置调整

- 从“关于 → 更新设置”移除重复的应用主题选择。
- 跟随系统、深色和浅色主题继续保留在主界面“应用偏好”中，与语言设置放在同一区域。
- “关于”窗口现在只负责应用信息、更新设置和诊断，页面副标题与中英文说明同步调整。
- README 与使用教程已经更新，不再引导用户前往“关于”页面修改主题。

## 虚拟摄像头构建维护

- 调整 Media Foundation COM 接口实现中的参数命名，避免与继承接口或成员名称产生遮蔽警告。
- 修改只涉及实现签名中的局部参数名称，不改变 COM 接口、GUID、媒体类型、帧传输或注册行为。
- Release 原生构建继续保持警告清晰，后续真正的兼容性警告更容易被识别。

## 兼容性与升级

- 支持 Windows 10 1809 及以上版本和 Windows 11 x64。
- 可直接覆盖安装 v1.5.6；主题、语言、更新选项和设备设置继续保存在 `%LOCALAPPDATA%\iPhoneMirror`。
- 没有新增第三方运行时依赖，也没有修改用户设置文件格式。
- 公开发布包不包含 Apple Mobile Device Support、iTunes 或其他 Apple 专有二进制文件。
- 有线投屏仍需要 Apple Devices，或包含 Apple Mobile Device Support 的桌面版 iTunes。

## 已知限制

- 当前安装程序未使用商业 Authenticode 证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从项目官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- 主题切换只影响 iPhoneMirror 自身窗口，不会更改 Windows 系统主题或其他应用的外观。
- QuickTime Screen Capture 与兼容 AirPlay 实现并非 Apple 官方稳定接口，未来 iOS 更新仍可能需要适配。
