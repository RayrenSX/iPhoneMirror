# iPhoneMirror v1.5.11

v1.5.11 是一次聚焦有线投屏音频连续性和 USB 关闭恢复稳定性的补丁更新。它主要修复部分新款 iPhone、较大 PCM 音频包以及多设备同时投屏时出现的间歇性断音，并进一步收紧 QuickTime USB 配置退出、设备重枚举和会话交接流程。

本版本不更换 USB 驱动，不删除任何现有投屏方式，也不改变用户设置格式。USB Screen Capture、AirPlay、音频播放、截图、录制、推流、OBS 输出、虚拟摄像头、多设备和独立窗口功能均继续保留。

## 用户可见修复

- 修复有线投屏过程中偶发的断断续续、短暂静音和连续音频丢帧。
- 改善部分设备使用 2048 或 4096 帧 PCM 音频包时的播放稳定性，不再按旧设备常见的 1024 帧包大小错误裁剪缓冲。
- 改善两个 iPhone 同时有线投屏时的音频连续性，独立设备的 USB 媒体读写仍可并行执行。
- 避免 WASAPI 端点缓冲较小时过早开始播放，降低刚开始出声后立即欠载的概率。
- 音频积压时只丢弃真正超过自适应高水位的旧数据，不再清空本应保留的抖动缓冲。
- 改善停止投屏、取消启动或采集异常后的 USB 恢复，降低手机停留在 QuickTime 配置、下次启动无法打开或需要重新插拔的概率。
- 避免停止一个设备时的关闭和恢复流程与另一设备的启动流程交错。

## 有线音频缓冲

- WASAPI 启动阈值和队列高水位现在根据最近观察到的最大音频包与实际端点缓冲动态计算。
- 为 1024、2048 和 4096 帧音频包保留与其大小匹配的抖动余量。
- 启动播放前等待完整的动态预缓冲，不再把约 1056 帧的端点容量误当成足够的启动数据。
- 大包到达时仅丢弃超过高水位的部分，避免把刚积累出的整段抖动储备移除后立即发生欠载。
- 音频包尺寸估计使用最近 16 个包的窗口，一次异常聚合大包不会永久抬高后续启动延迟。
- 阈值计算和入队规划使用有界饱和运算，防止极端格式或包尺寸造成容量溢出。
- 高频 `queue_catchup` 日志改为只记录最初事件和每 100 次摘要，避免日志写入反过来放大实时音频线程压力。
- 播放启动日志现在记录队列深度、启动阈值、高水位和近期最大包尺寸，便于继续诊断不同设备的音频行为。

## USB 并发与错误处理

- `libusb0` 的设备发现、配置切换、接口打开和关闭继续使用排他锁。
- 已经打开的不同设备之间，bulk 读写继续使用共享锁并行排水，避免一个设备最长 250 ms 的读取等待阻塞另一台设备的媒体流。
- bulk 超时通过 libusb-win32 的稳定数值返回码识别，不再从并发路径读取进程级、非线程安全的 `usb_strerror()` 缓冲。
- 非超时 bulk 错误保留明确的数值错误码，避免多设备错误文本互相覆盖或串台。
- `libusb0` 关闭路径交由 `usb_close` 统一释放接口，不再在 PnP 拆卸期间先执行一次可能失败的显式 release，再由 close 重复释放。

## QuickTime USB 配置恢复

- 新增显式恢复状态策略，区分设备暂时缺失、普通 USB 配置和 QuickTime USB 配置。
- 每次恢复最多发送一次 `0x52` 退出请求；即使该请求触发预期的 I/O 错误或设备断开，也不会重复发送。
- 先关闭已 claim 的流式句柄并等待 legacy libusb 完成释放，再使用独立、未 claim 的控制句柄请求退出 QuickTime 配置。
- 不再在发送 `0x52` 后立即对正在断开的句柄强制切换 USBMux 配置，改由 iOS 完成正常重枚举。
- 停止、异常和取消路径会串行完成媒体停止、句柄关闭、配置恢复与后端身份释放，之后才允许其他会话进入 USB 配置切换阶段。
- 正常配置已经重新出现时立即结束恢复；设备仍在重枚举时继续观察，但不会重复执行破坏性的退出请求。

## 驱动维护工具

源码仓库新增 `Remove-Selected-iPhone-Drivers.cmd` 和 `scripts/remove_selected_iphone_drivers.ps1`，用于高级故障排查时按设备清理第三方 iPhone/iPad 驱动。该工具不包含在安装器或便携 ZIP 中。

- 只允许选择当前仍通过 USB 连接的 iPhone/iPad。
- 支持 `-ListOnly` 列表模式和 `-PreviewOnly` 只预览模式。
- 执行前展示将移除的 PnP 节点和匹配到的 `oem*.inf` Driver Store 包。
- 当驱动包仍被其他设备使用时给出明确警告。
- 实际删除需要管理员权限，并要求输入包含所选设备序列号尾部的二次确认文本。
- 操作前再次检查手机仍然连接，避免用户确认后选中对象发生变化。
- 清理过程生成 JSON 清单与完整日志，便于后续审计和恢复。
- 不删除 Apple Devices、iTunes、Apple Mobile Device Service 或 Windows 系统文件。

## 兼容性与升级

- 支持 Windows 10 1809 及以上版本和 Windows 11 x64。
- 可直接覆盖安装 v1.5.10；主题、语言、更新选项和设备设置继续保存在 `%LOCALAPPDATA%\iPhoneMirror`。
- 没有升级或静默安装新的 USB 驱动，也没有新增第三方运行时依赖。
- 公开发布包不包含 Apple Mobile Device Support、iTunes 或其他 Apple 专有二进制文件。

## 已知限制

- 为提高连续性，使用 4096 帧大音频包的设备首次出声可能比旧策略稍晚，通常仍在约百毫秒量级。
- 自动化测试覆盖缓冲算法和完整 Windows 组件，但不同 iPhone/iOS 组合的双设备长时间播放仍建议进行 5 至 10 分钟真实硬件验证。
- 驱动清理工具会删除匹配的第三方 Driver Store 包；共用同一 INF 的其他 Apple 设备之后可能需要重新安装驱动。请先使用 `-PreviewOnly` 并阅读全部警告。
- 当前安装程序未使用商业 Authenticode 证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从项目官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- QuickTime Screen Capture 与兼容 AirPlay 实现并非 Apple 官方稳定接口，未来 iOS 更新仍可能需要适配。
