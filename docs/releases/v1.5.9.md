# iPhoneMirror v1.5.9

v1.5.9 是一次聚焦界面一致性和可读性的补丁更新。更新窗口的发布说明区域不再显示传统 WPF 粗滚动条，而是与主界面设置区域共用同一套细窄、圆角、主题感知并带平滑悬停动画的滚动条。浅色模式下所有蓝色动作按钮均稳定使用白色文字，其中包括更新窗口右下角的“立即更新”按钮。

本版本继续使用 FluentWindow、NavigationView、Mica/Acrylic、现代 Card、圆角控件、Snackbar/Dialog、Dark/Light Theme 和现有页面动画体系，没有重新引入传统 WPF 默认控件外观。

## 更新窗口

- 更新说明区域的 `FlowDocumentScrollViewer` 显式继承共享现代滚动条样式。
- 右侧滚动条采用与主界面设置面板相同的内容边缘样式和 6 px 右移参数。
- 滚动条仍保留独立布局空间，不会覆盖发布说明文字，也不会与圆角 Card 边框重叠。
- 默认状态下轨道尽量融入 Mica/Card 表面，鼠标悬停时再显示更明确的轨道反馈。
- “立即更新”按钮显式使用主题动作文字画刷，浅色模式下保持白色文字。
- 更新按钮继续保留深色模式的原有高对比度配色、禁用状态和下载状态行为。

## 全局滚动条统一

- 将完整滚动条模板集中为 `ModernScrollBarStyle`，作为应用和驱动管理器的唯一基础样式。
- 所有未单独指定样式的 `ScrollBar` 自动通过全局隐式样式继承现代模板。
- 主界面设置区和更新说明区共同使用 `ContentEdgeScrollBarStyle`，避免重复维护偏移参数。
- 纵向滚动条布局槽宽度为 6 px，默认滑块宽度为 2 px。
- 横向滚动条布局槽高度为 6 px，默认滑块高度为 2 px。
- 鼠标悬停时滑块通过缓动动画扩展到 4 px，并淡入轻量轨道。
- 拖动时使用主题按下状态画刷，禁用时降低透明度。
- 滑块最小长度保持 28 px，短内容和长文档均具有稳定的可操作区域。
- 纵向和横向滚动继续使用正确的 PageUp、PageDown、PageLeft 与 PageRight 命令。
- `ScrollViewer`、`FlowDocumentScrollViewer`、`ListBox`、组合框下拉列表、可滚动文本框及驱动管理器滚动区域均使用同一基础视觉语言。

## 浅色主题按钮可读性

- 修复全局 `TextBlock` 样式覆盖 `PrimaryButton` 前景色的问题。
- 主按钮模板改为显式渲染主题前景色，避免生成的内部文本重新继承普通黑色文字。
- 更新窗口“立即更新”、关于页面“检查更新”、设置保存、确认、重试和安装等蓝色主按钮在浅色模式下统一显示白色文字。
- 主窗口开始投屏按钮继续使用白色动作文字，并保持停止投屏时的红色状态设计。
- 驱动管理器的安装、重试和确认按钮继续复用相同主题动作文字资源。
- 深色模式仍使用为浅蓝强调背景设计的深色文字，没有强制改成不合适的白色。
- 禁用按钮继续使用单独的禁用背景和文字画刷，不会把不可用操作伪装成可点击状态。

## 自动化验证与维护

- 新增真实 WPF 运行时测试，直接检查更新按钮模板内部实际渲染出的文字颜色。
- 浅色模式断言按钮文字为纯白色，深色模式断言保持原有深色高对比度文字。
- 运行时测试遍历更新说明控件的真实视觉树，确认内部纵向滚动条使用共享模板。
- 自动验证滚动条 6 px 布局宽度、2 px 默认滑块和 6 px 右侧偏移，防止只修改资源名称却没有改变实际控件。
- 静态测试核对浅色主题中全部蓝色动作文字画刷均为白色。
- 静态测试核对主界面和更新窗口都引用同一个内容边缘滚动条样式。
- GitHub Actions 使用固定的 `Windows build` 运行名称，避免运行标题随提交或合并标题变化。

## 兼容性与升级

- 支持 Windows 10 1809 及以上版本和 Windows 11 x64。
- 可直接覆盖安装 v1.5.8；主题、语言、更新选项和设备设置继续保存在 `%LOCALAPPDATA%\iPhoneMirror`。
- 不修改 USB Screen Capture、AirPlay、H.264/CoreMedia 解码、音频渲染、录制、推流、OBS 输出、虚拟摄像头协议或驱动安装协议。
- 不修改用户设置文件格式，也没有新增第三方运行时依赖。
- 公开发布包不包含 Apple Mobile Device Support、iTunes 或其他 Apple 专有二进制文件。

## 已知限制

- 当前安装程序未使用商业 Authenticode 证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从项目官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- QuickTime Screen Capture 与兼容 AirPlay 实现并非 Apple 官方稳定接口，未来 iOS 更新仍可能需要适配。
- 滚动条视觉会跟随浅色或深色主题变化，但 Windows 自身的高对比度辅助模式可能进一步覆盖部分颜色。
