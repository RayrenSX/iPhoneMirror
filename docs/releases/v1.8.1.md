# iPhoneMirror v1.8.1

v1.8.1 是面向 v1.8.0 的稳定性与可用性修复版本，重点改进蓝牙反向控制在多设备场景下的路由可靠性、快捷键体验和驱动安装恢复能力，同时完善无线投屏连接和正式发布校验。

## 蓝牙反向控制

- 每台镜像设备现在只绑定到明确匹配的蓝牙 HID 客户端。多个 iPhone/iPad 同时连接时，鼠标、键盘和系统快捷键不会再广播到其他设备。
- 首次为设备启用反向控制时会显示蓝牙客户端绑定窗口，可查看设备名称、地址和连接时间，并手动确认对应手机；之后切换镜像设备会自动沿用已保存的绑定。
- 绑定客户端断开后不会自动把控制权转移给另一台手机；客户端重新连接后恢复原绑定，避免误操作。可在设置中解除单个绑定或清除全部绑定。
- 蓝牙启停、设备切换、独立窗口关闭和会话结束均使用串行路由更新，并在切换期间释放鼠标、键盘和系统按键状态。
- 新增键盘快捷键设置窗口，可配置反向控制、控制中心、通知中心、主屏幕、App 切换器、Boss 键、程序坞和 Siri 等操作；支持冲突检测、恢复默认和取消绑定。
- 反向控制快捷键改为可配置的全局热键，配对提示会显示当前快捷键；Boss 键可隐藏或恢复主窗口及独立预览窗口。
- 改进 BLE GATT 回调异常处理、通知超时和断开恢复；鼠标移动在发送队列中合并并限速，保留完整移动距离，同时优先发送按键按下与释放事件。
- HID 报告地图加入 iOS 系统导航和 App 切换支持。由于报告格式发生变化，升级后需要在 iPhone/iPad 上忽略旧的 iPhoneMirror 配对并重新配对。

## 有线投屏与设备识别

- 横屏画面长时间没有有效帧率时允许后续独立的 QuickTime 快速重连尝试；视频恢复后会解除重连闸门，避免同一会话无法再次恢复。
- Apple USB 设备识别改用明确的 iPhone/iPad 产品 ID 清单，排除 Apple USB-C 音频适配器、Apple TV、Apple Watch 和 HomePod 等非镜像设备。
- 构建时从统一的产品 ID 配置生成 native、托管和驱动清理工具使用的清单，并在测试中校验三者一致。

## 驱动安装与清理

- 驱动安装器可以修复不匹配的 `libusb0.dll` 系统文件；替换过程使用备份、校验和回滚，失败时恢复原文件。
- 增加受保护的驱动清理入口，按物理 iPhone/iPad 设备分组显示设备节点和 Driver Store 驱动包，过滤 Bluetooth LE 节点并支持预览模式。
- 驱动清理脚本嵌入安装器并进行完整性校验，管理员边界由安装器负责，避免直接调用不受信任的脚本副本。

## 无线投屏与发布

- 安装程序自动维护无线 AirPlay 接收端的本地子网防火墙规则，覆盖 TCP `5001`、`7001`、`7100`、`8090` 和 UDP `1900`；卸载时删除专用规则。
- 用户指南补充无线连接失败、访客网络、VPN、AP 隔离和便携版手动防火墙配置说明。
- 正式发布包、便携 ZIP、SPDX SBOM 和 SHA-256 清单由 GitHub Windows 流程生成并逐项校验，发布清单同步更新到 `updates/releases.json`。

This is a stability and usability release following v1.8.0. It improves Bluetooth reverse-control routing, configurable shortcuts, driver repair and cleanup, wireless connectivity, and release validation.

### Added

- Add explicit Bluetooth HID client binding for each mirrored iPhone/iPad, with a confirmation window showing the client name, address, and connection time.
- Persist per-device Bluetooth bindings, provide manual bind/unbind and clear-all actions, and prevent a disconnected client from being silently replaced by another phone.
- Add a configurable global shortcut window with duplicate detection, reset and unbind support for reverse control, iOS navigation commands, App Switcher, Boss key, Dock, and Siri.
- Add iOS Consumer Control and navigation HID reports, plus a pairing-refresh notice for the updated report map.
- Add a generated Apple mobile capture product-ID source shared by native discovery, managed driver logic, and the cleanup tool.

### Changed

- Serialize Bluetooth start, stop, target switching, independent-window changes, and input release operations so stale routes cannot retain control.
- Coalesce and pace relative mouse reports while prioritizing keyboard and system shortcut transitions.
- Use an explicit Apple mobile USB product table to distinguish iPhone/iPad capture devices from unrelated Apple accessories.
- Extend the installer with a dedicated local-subnet firewall rule for the wireless AirPlay host and document portable-install firewall setup.

### Fixed

- Prevent Bluetooth HID reports from being delivered to every subscribed phone when multiple clients are connected.
- Preserve a selected device's route after temporary client disconnects and restore it when the same client returns.
- Recover mismatched `libusb0.dll` system files transactionally and restore the original files after a failed replacement.
- Prevent repeated fast reconnect loops during a stalled landscape stream while allowing a later independent recovery attempt.
- Harden GATT callback and notification timeout handling so disconnects do not leave input state or background tasks stuck.
- Filter non-mobile Apple USB products out of capture discovery and driver cleanup.

### Notes

- Existing iPhone/iPad Bluetooth pairings must be forgotten and re-created once after upgrading because the HID report map changed.
- Wireless reverse control still requires iPhone AssistiveTouch and a Windows Bluetooth adapter that supports BLE peripheral mode.
