# iPhoneMirror v1.7.0

v1.7.0 是基于 v1.6.9 的正式稳定版更新。版本继续保留 USB 有线投屏、
AirPlay/DLNA 接收、媒体投屏、录制、直播推流、虚拟摄像头和独立预览，
并集中改进窗口体验、网络路由、OBS 兼容性、安装安全和发布验证。

## 虚拟摄像头与 OBS 兼容性

- 修复 Windows Frame Server 二维视频缓冲区存在额外行步长时的逐行错位、横向条纹和花屏。
- 使用 `IMF2DBuffer2::Lock2DSize` 返回的实际 scanline、pitch 和缓冲区长度逐行写入，
  并在写入后同步样本有效长度。
- 虚拟摄像头媒体源默认只发布 RGB32，避开 OBS 对带填充 NV12 平面的兼容差异。
- 虚拟摄像头输出宽度按最近的 16 像素边界取整，保证 RGB32 行布局与常见 Frame Server
  对齐方式一致；例如 994 会取整为 992。
- 保留源画面的宽高比适配，不强制横屏时竖屏、不中心裁剪，也不拉伸画面；OBS 横向画布
  显示竖屏摄像头时产生的左右空白属于比例适配结果。
- 帧共享通道继续限制为当前用户和 Windows Frame Server 身份，降低未授权读写风险。

## 界面与预览

- 使用随应用发布的 WPF-UI 4.3.0 和 Fluent 图标，替换依赖系统字体的旧图标字符。
- 统一主窗口、子窗口、设置窗口、更新窗口和提示窗口的标题栏、拖拽区域、关闭按钮、
  主题资源、焦点反馈和圆角策略。
- 改进浅色/深色主题的强调色、成功色、警告色、错误色和标题栏图标对比度。
- 修复页面切换透明度残留、关闭按钮被拖拽事件拦截、重复外框和圆角伪影。
- 独立预览窗口在横竖屏、旋转、混合 DPI、多显示器和高 DPI 环境下保持稳定尺寸和居中行为，
  并移除由整数宽高比舍入造成的一像素黑边；真实的比例黑边仍然保留。
- 增加只读开发工具和界面预览入口，用于检查窗口布局、主题、DPI、诊断信息和关闭行为，
  不执行真实设备、网络、更新或删除操作。

## 媒体投屏与播放

- 延续 v1.6.9 的连续 HLS 播放、队列媒体信息、暂停/继续、跳转、音量/静音、倍速、录制、
  RTMP/SRT/WHIP 推流和媒体源音频同步能力。
- AirPlay 媒体 socket 绑定到已接受控制连接对应的网络接口，并保留 IPv4/IPv6 路由，
  避免多网卡或虚拟网络环境中的媒体包走错接口。
- 录制与推流继续使用原生 NV12 输出、比例保持的画布和硬件编码器优先策略，编码回压不会
  阻塞 WPF UI 线程。

## USB、安装与发布安全

- Apple USB 设备继续按精确 VID/PID、拓扑和序列信息匹配，并只在确认需要时恢复 USB 配置。
- 更新助手和虚拟摄像头安装继续通过 UAC、哈希验证、受保护 staging 目录和路径权限检查，
  防止从用户可写目录加载被替换的组件。
- 安装包和便携包包含应用、驱动管理器、无线接收组件、虚拟摄像头、FFmpeg、第三方声明、
  SPDX 2.2 SBOM 与 SHA-256 清单；发布脚本会校验版本、文件集合、运行库和所有公开资产。
- 应用、驱动管理器、原生核心、USB 客户端和安装器版本统一为 1.7.0。

## 验证

- Windows x64 Release 原生 CTest、应用逻辑测试、应用运行时测试、驱动安装器测试、无线
  接收 smoke test、网络媒体路由测试、Visual C++ 运行库解析测试和 Apple 支持包验证通过。
- 面向 Windows 10/11 x64，支持从 v1.6.9 覆盖升级。

### Added

- Add packaged Fluent icons, read-only developer previews, expanded release validation, and
  AirPlay media-route diagnostics.
- Add RGB32 Frame Server output validation, allocator-backed virtual-camera coverage, and
  release-package license and SBOM checks.

### Changed

- Standardize application and child-window chrome, theme contrast, title-bar controls, preview
  sizing, DPI handling, and aspect-ratio rendering.
- Bind AirPlay media sockets to the accepted control route while preserving IPv4 and IPv6,
  and keep release scripts strict about versions, hashes, payloads, and generated manifests.

### Fixed

- Fix OBS virtual-camera row-stride interpretation that caused horizontal tearing, shifted rows,
  and corrupted frames when Windows Frame Server supplied padded two-dimensional buffers.
- Fix one-pixel native preview bars, stale page opacity, title-bar drag/close conflicts, and
  several release-payload and runtime-integrity validation gaps.
