这是用于功能和兼容性测试的 **Windows x64 预览版**，汇总自 v1.8.5-pre4 以来的变更。主要更新包括顶部工具栏自定义、主界面布局优化、实验性蓝牙绝对鼠标、独立窗口设置快捷键，以及连接、输入和配置保存修复。

### 顶部工具栏与聚焦编辑

- 在应用设置或工具栏右键菜单进入“自定义顶部工具栏”。保留原有八项工具，日常使用继续采用单行布局和现有主题底色。
- 新增聚焦编辑界面：原工具栏可见时，主界面适度向上放大，四周以柔边黑色渐变暗化；底部集中显示组件库、仅图标、恢复默认、取消和完成。
- 原工具栏因轻量模式或手动设置而隐藏时，编辑栏从顶部轻微滑入并淡入，背景保持原位；退出时反向恢复，避免从不存在的位置放大。
- 直接按住工具并拖动即可排序，拖动时显示跟随指针的卡片和原位置占位，邻近工具平滑让位。取消拖动、失去鼠标捕获或按 Esc 时恢复当前这次拖动前的顺序。
- 选中工具后只显示名称与隐藏操作；隐藏的工具可从组件库重新加入。保留 Delete 隐藏和 Alt+左右方向键排序；隐藏最后一项时自动打开组件库。
- 编辑预览按自然宽度完整横向排开，并随可用宽度适配比例，不显示两端箭头、横向滚动条或多行工具。编辑期间不会执行工具的真实业务命令。
- 完成后保存顺序、显隐和仅图标配置，重启后恢复；取消或关闭编辑窗口恢复进入前的配置。Esc 按拖动、组件库、编辑界面的顺序逐级退出。
- 改用 WPF 呈现变换和透明度动画，复用背景快照、渐变纹理与工具控件，减少动画中的重复截图和布局计算。视觉效果采用固定值，不增加视觉参数设置页。
- 修复最大化、全屏、还原和拉伸后编辑层尺寸或位置不同步的问题；编辑快照中的投屏画面保持原始比例，避免被横向拉宽。

### 主界面、设置与窗口布局

- 完整模式不再被原先 800 DIP 的宽度下限固定，在空间允许时可缩至 480 DIP；横向收缩优先减少预览两侧黑边，并保留当前显示画面的宽度约束。
- 重新约束轻量模式的预览宽度，避免同时打开左右面板时被挤成过窄的竖条；改善窄窗口下标题、操作按钮、侧栏和预览的对齐。
- 顶部预览工具和底部状态指标保持单行，避免音频信息掉到第二行；宽度不足时采用紧凑显示或必要的单行滚动。
- 设置保持“应用、投屏、反控”三个直接显示的分类，改善内容宽度、独立滚动条、短窗口和大字号下的布局。
- 应用模式移到应用主题下方，三个隐藏选项集中排列。切换轻量模式时同步显示实际隐藏状态，返回完整模式时恢复原有完整模式偏好。
- “隐藏界面描述文字”同时覆盖新增的设置说明；移除“本机 USB / AirPlay，无云端中转”页尾文字，减少重复信息。
- 修复部分下拉选项在绑定、切换语言或订阅通知后无法保留选择的问题；加强主题、模式、画面参数和自动反控设置的保存失败回滚与反馈。
- 通用鼠标方向与蓝牙专属参数分别展示，改善应用按钮、待应用状态和错误提示，保存失败时保留可重试的修改。
- 将选点操作移到镜像画面外，避免“点击目标位置”浮层挡住手机内容；清理部分设置按钮和页签的重复焦点外框。

### 反向控制与蓝牙输入

- 统一三种反向控制方式的状态窗口和连接进度。自动反控的常规准备、恢复和成功过程保持静默；手动连接、错误和必要的用户操作继续显示窗口。
- 修复自动反控偏好无法保留的问题。修改后可对已有投屏尝试一次，忙碌结束后继续处理；手动停止的连接不会被下一次轮询立即重新开启。
- 蓝牙设备设置支持取消，限制发现等待时间，关闭所属窗口时结束关联提示和待完成操作，改善“正在准备蓝牙连接”无法退出的情况。对应 [#86](https://github.com/RayrenSX/iPhoneMirror/issues/86) 的设置生命周期部分，不将升级配置覆盖问题计为全部解决。
- 蓝牙连接成功后显示实际配置的提示：“按 {快捷键} 释放鼠标并暂停输入，再按一次恢复控制。”准备、失败和取消状态不再显示可操作的成功提示。关联 [#87](https://github.com/RayrenSX/iPhoneMirror/issues/87)。
- 集成主预览与独立窗口的蓝牙绝对位置鼠标，支持在 Windows 桌面和镜像区域之间移动指针；该功能仍标为实验性，默认关闭。来源与后续修复关联 [#82](https://github.com/RayrenSX/iPhoneMirror/pull/82)。
- 修复绝对鼠标首次点击、滚动后定位、快速连点顺序、失败按下重试和连续拖动；按设备坐标换算拖动距离，保留松开前的最终移动。
- 减少长距离拖动的报告次数和额外等待，允许键盘事件在长移动之间处理；滚轮使用有界拖动手势，并保留边缘滚动的目标区域。
- 在暂停、失焦、离开画面、几何变化、队列溢出或释放失败时清理输入状态；阻止旧蓝牙客户端的延迟操作进入新连接。
- 改善独立窗口取消固定后的移动和缩放、重新固定或全屏后的输入恢复，以及实验模式下的右键菜单和双击全屏。相对鼠标模式继续保留原有右键转发行为。
- 修复鼠标侧键捕获中断绝对位置拖动，以及已保存蓝牙客户端在 HID 订阅与绑定查询重叠时无法完成启动的问题。

### 快捷键、输入法与剪贴板

- 快捷键设置底部新增独立卡片，可为独立预览窗口的透明度或置顶配置键盘组合键、鼠标按键及目标值。透明度支持 10%–100%，无需先开启手机反控。关联 [#77](https://github.com/RayrenSX/iPhoneMirror/issues/77)。
- 支持“点按切换”和“按住临时生效”：新建默认点按切换，再按一次恢复；旧配置保留按住行为，松开、失焦或关闭窗口时安全恢复。
- 改善 Windows 中文输入法处理后的按键转发、修饰键释放、快捷键识别和重新聚焦。Windows 搜狗中文模式下的 USB 主预览按键转发已有专项实测，关联 [#72](https://github.com/RayrenSX/iPhoneMirror/issues/72)；不扩大为所有输入法、控制方式和手机候选输入均已验证。
- 改善剪贴板请求超时、资源清理、富文本与转换器恢复，补充失败路径及协议回归检查。

### 投屏、设备操作与自动化

- 原始 AirPlay 接收方案支持自定义并保存 RAOP TCP 端口，默认 5001；提供合法性检查和端口占用提示。点击应用后重启接收端并更新广播，手机可重新发现新端口；UxPlay 的端口不受该设置影响。
- 设备卡片右键改为“复制设备信息、重启设备、关机”。操作针对右键点击的设备，不切换当前投屏来源；重启和关机需要确认，并按 USB、信任及忙碌状态限制可用性。
- 移除右键菜单中的“同时投屏”和“息屏”。息屏会导致部分设备断开连接，因此本版不再提供该入口；重启和关机本身仍会结束设备连接。
- Automation API 截图请求限制可在“开发者工具 → Automation API”中设为每秒 1–30 次，应用后保存并重启监听。新配置默认每秒 30 次，已有配置保持原值，需手动调整。
- 每秒 30 次是请求预算，不保证每秒得到 30 张不同 PNG；仍受视频帧更新、编码耗时与并发编码限制影响，共用凭据的调用方也共用请求预算。

### 更新、配置与文档

- 修复更新程序的 Shell 辅助任务在线程未正确初始化时失败的问题，改由初始化后的 STA 线程启动。
- 保留首次配置助手中的应用模式草稿，改善设置窗口关闭、取消和状态恢复；本版不宣称所有旧配置迁移或重新配置覆盖问题均已解决。
- 新增日文 README，更新使用指南、API 示例、设置入口和排障索引，补充工具栏自定义与第三方来源声明，并移除随附的个人下载镜像配置。
- 主程序与驱动管理器版本统一为 1.8.5-pre5。

### 升级与验证说明

- 从旧版升级前建议备份个人配置；如重新运行首次配置助手，请先核对选项。工具栏编辑的取消不会保存当前修改，原有快捷键及已保存截图限额按兼容规则保留。
- 自动构建覆盖原生测试、Python 测试、应用逻辑、驱动测试和五语资源检查；发布流程额外生成安装包、便携包、可选 UxPlay 组件、软件物料清单及 SHA-256 校验清单。
- 本地专项回归涵盖工具栏、设置、蓝牙连接取消、连接提示、设备菜单和控制生命周期；需要交互桌面的 WPF 窗口回归不会作为 GitHub 托管环境的完整桌面验收。
- 物理跨屏 DPI、所有机型的持续视频表现及实验性蓝牙绝对鼠标仍需实际环境反馈。本版不宣称已解决 BGMI 4K 开麦掉帧、特定 iOS 的 AirPlay 发现问题，也未新增完整游戏摇杆／无限视角映射或 macOS 客户端。

### Added

- Add a focused editor for the top preview toolbar, available from Application settings or its context menu. Keep the original eight tools, a single row and the existing theme background in normal use.
- Add a component library, direct drag reordering, hide/restore actions, icon-only display, reset, cancel and persistent save. Hidden tools can be added back; hiding the last tool opens the library.
- Add keyboard support for Delete to hide and Alt+Left/Right to reorder. Esc cancels a drag, closes the library or exits editing in that order; editor buttons do not execute their production commands.
- Add independent-window setting shortcuts for opacity (10–100%) and topmost, configurable with keyboard chords or mouse buttons without enabling phone control. [#77](https://github.com/RayrenSX/iPhoneMirror/issues/77)
- Support toggle and hold behavior. New bindings default to toggle; older bindings retain hold behavior, including restoration on release, loss of focus or window closure.
- Integrate experimental absolute Bluetooth mouse input in main and independent previews, with movement between Windows and the mirrored image. It remains disabled by default. [#82](https://github.com/RayrenSX/iPhoneMirror/pull/82)
- Add a persistent RAOP TCP port setting for the original AirPlay receiver, defaulting to 5001. Validate values and port availability, then restart and re-advertise the receiver on Apply. UxPlay retains its own port configuration.
- Add Copy device information, Restart and Shut down to device context menus. Target the clicked device without changing the current source; power actions require confirmation and an available, trusted USB device.
- Expose the Automation API screenshot budget in Developer tools with a range of 1–30 requests per second. New configurations default to 30; existing saved limits remain unchanged until edited and applied.

### Changed

- Focus a visible toolbar with an upward scene transform and soft dark vignette. When the toolbar is hidden, slide and fade the editor in from the top while keeping the background stationary; reverse the transition on exit.
- Keep all editor tools on one adapted row without edge arrows, horizontal scrollbars or wrapping. The bottom bar contains only the library, icon-only option, reset, cancel and done.
- Reuse scene snapshots, vignette textures and tool controls; use WPF render transforms and opacity animations instead of repeating full-scene captures or layout work throughout the transition.
- Keep complete mode resizable below the old 800 DIP minimum, down to 480 DIP where space permits. Reduce surplus black margins while respecting the currently displayed picture width.
- Bound lightweight preview width and refine narrow-window header, side-panel and preview alignment. Keep preview tools and status indicators on one row with compact presentation or necessary single-row scrolling.
- Retain three directly visible settings categories: Application, Projection and Reverse control. Improve scrolling, content widths, short windows and large-text layouts.
- Place application mode below theme, group the three hide options and reflect lightweight mode's effective state while preserving complete-mode preferences.
- Keep routine automatic-control preparation, recovery and success silent. Manual connections, failures and required user actions still use the status dialog.
- Dock point-picking actions outside the mirrored picture, remove redundant focus borders and the obsolete connectivity footer, and apply the hide-description preference to new settings guidance.
- Remove the old simultaneous-mirroring and sleep entries from device menus. Sleep can disconnect affected devices; restart and shutdown intentionally end the connection.
- Add a Japanese README, refresh guides and API examples, document toolbar attribution and remove a personal download mirror from the shipped configuration.

### Fixed

- Keep the editor aligned through maximize, full screen, restore, resizing and DPI changes. Preserve the video's original aspect ratio in scene snapshots instead of stretching it to the preview bounds.
- Restore the pre-edit configuration when cancelling or closing the editor; retain the previous drag order on Escape or lost mouse capture.
- Make Bluetooth setup cancellable, bound discovery waits and retire owned prompts and pending setup when the owner closes. This addresses the setup lifetime portion of [#86](https://github.com/RayrenSX/iPhoneMirror/issues/86), not all reported upgrade or configuration-loss scenarios.
- Show the actual configured mouse-release shortcut only after Bluetooth control connects, and hide it during preparation, failure and cancellation. Pressing it releases the mouse and pauses input; pressing again resumes control. [#87](https://github.com/RayrenSX/iPhoneMirror/issues/87)
- Preserve automatic-control selections, apply changed preferences to existing streams once, resume after busy guards clear and retain manual-stop behavior instead of immediately reconnecting on the next poll.
- Fix selector identity and selection persistence across notification subscriptions and localization; improve apply feedback and transactional rollback for settings save failures.
- Separate shared mouse-direction settings from Bluetooth-specific parameters and retain retryable edits when saving fails.
- Fix absolute Bluetooth first-click and post-scroll positioning, rapid click order, failed-press recovery and consecutive drags. Scale travel to device coordinates and preserve final movement before release.
- Reduce long-drag report count and extra waits, allow keyboard delivery between motion segments and keep bounded wheel gestures on their requested edge-scrolling surface.
- Clean up input on pause, focus loss, leaving the picture, geometry changes, queue overflow or release failure; reject stale work from replaced Bluetooth clients.
- Restore moving/resizing unfixed independent previews and input after refixing or full screen; align experimental-mode context menus and double-click full screen while retaining relative-mode right-click forwarding.
- Fix side-button capture interrupting absolute drags and saved-client startup when HID subscription overlaps binding discovery.
- Improve Windows IME key forwarding, modifier release, shortcut recognition and refocus recovery. USB main-preview forwarding in Windows Sogou Chinese mode has targeted live evidence for [#72](https://github.com/RayrenSX/iPhoneMirror/issues/72); this does not imply every IME, transport or phone candidate-entry path was tested.
- Improve clipboard timeout handling, resource cleanup, rich-text and converter recovery, with regression checks for protocol failures.
- Start updater shell helpers on an initialized STA thread.
- Preserve application-mode drafts in first-run setup and improve cancellation, closure and state restoration. Align application and driver manager versions at 1.8.5-pre5.

### Notes

- Back up personal settings before upgrading from older versions and review choices before rerunning first-run setup. Configuration migration and overwrites are not claimed universally resolved.
- Screenshot rate is a request budget, not a guarantee of 30 distinct PNG frames per second. Frame availability, encoding time and encoder concurrency still apply; callers sharing a credential share its budget.
- Automated validation covers native code, Python, application logic, drivers and five-language resources. Release packaging produces the installer, portable archive, optional UxPlay component, SBOM and SHA-256 manifest.
- Targeted local regressions cover toolbar editing, settings, Bluetooth cancellation and hints, device menus and control lifecycle. GitHub-hosted runners do not provide full interactive WPF desktop acceptance testing.
- Physical cross-monitor DPI, sustained video across all devices and experimental absolute Bluetooth input still require field feedback. BGMI 4K/microphone freezing and iOS-specific AirPlay discovery are not declared fixed; complete game-control mapping and a macOS client are not included.
