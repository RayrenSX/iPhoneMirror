# iPhoneMirror v1.8.3

v1.8.3 是一个紧急修复版本，解决从 1.8.1 直接升级到 1.8.2 后反向控制无法加载 USB 运行时的问题。

⚠⚠⚠紧急修复⚠⚠⚠
1.8.1 直接升级到 1.8.2 后反控找不到 `libusb0.dll` 的问题。

## 紧急修复

- 修复从 1.8.1 直接升级到 1.8.2 后，反控找不到 `libusb0.dll` 并提示“没有可用的 libusb 后端”的问题。
- 反控桥接器启动时现在会显式使用主程序目录、桥接器目录及其内部运行时目录，不再依赖系统全局 `PATH` 或额外安装 Python 包。
- 安装版覆盖升级和便携版 ZIP 覆盖升级均使用相同的运行时查找逻辑。

## 验证

- Windows x64 Release 应用和反控启动逻辑通过构建与自动化测试。
- 正式发布资产继续校验名称、大小、SHA-256、SBOM 和更新清单一致性。

v1.8.3 is an emergency maintenance release that fixes USB runtime discovery for reverse control after upgrading directly from 1.8.1 to 1.8.2.

### Fixed

- Fix reverse control failing with "no available libusb backend" because `libusb0.dll` could not be found after a direct 1.8.1-to-1.8.2 upgrade.
- Add the application, bridge, and bundled bridge-runtime directories to the bridge process's DLL search path.
- Apply the same runtime discovery behavior to installer and portable ZIP upgrades without requiring a system-wide `PATH` change or an additional Python package.

### Verification

- Validate the Windows x64 Release application and reverse-control startup path through the existing build and automated test suites.
- Continue validating release asset names, sizes, SHA-256 digests, SBOM data, and update-manifest consistency.
