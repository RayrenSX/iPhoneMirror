# iPhoneMirror v1.5.0

v1.5.0 是一次完整的桌面界面整理，同时补充了本地 USB 配置失败时的可操作恢复提示。主程序、驱动管理器、所有子窗口、安装器和便携版均统一到同一版本。

## 主界面重新设计

主界面改为紧凑的左侧导航栏和按需展开的工作区，减少无关卡片占用，把高频操作保持在预览画面附近：

- 投屏、设备、输出、设置、驱动管理器和关于入口统一到左侧导航栏。
- 设备、投屏方式和设置面板按需展开，并使用连续的宽度动画，避免预览区跳动。
- 截图、独立窗口、画面设置、刷新和全屏操作集中到预览区上方。
- 主界面的实时日志不再占据预览工作区，完整日志入口移到“关于 > 诊断”。
- 最大化、还原和全屏切换统一处理窗口边框、圆角和预览尺寸。

## 黑灰白简约视觉

普通界面元素收敛到黑、灰、白三色：

- 普通按钮、选中态、焦点框、标签页和导航状态不再大面积使用蓝色。
- 右上角“开始投屏”保留蓝色，“停止投屏”保留红色，便于快速识别当前操作。
- 警告、错误和必须注意的提示区域继续保留有限的语义颜色。
- 图标按钮悬停改为明暗主题适配的半透明灰色圆角矩形，不再出现系统默认方形底。
- 主程序和驱动管理器共用相同主题资源、控件圆角、边框透明度和交互反馈。

## 浅色预览区修复

此前浅色模式下，中间预览区仍被硬编码为接近纯黑，等待设备和准备投屏的占位内容也固定使用白色文字。

v1.5.0 将预览背景、手机轮廓、连接方式、设备名称和状态文字全部改为主题资源：

- 浅色模式使用浅灰预览底、白色辅助面和深色文字/图案。
- 深色模式继续使用接近黑色的预览底和浅色文字。
- 两种模式都保留明确的边框和次要文字对比度。
- 预览切换遮罩跟随当前主题，不会在浅色模式切换时闪出黑块。

## 关于与所有子窗口统一

“关于”窗口去掉包住整页内容的大卡片，改为轻量的无框分区：

- 关于、更新设置和诊断使用同一套等宽标签页。
- 产品信息、更新状态、主题选择和日志操作采用一致的标题层级与间距。
- 版本号和普通操作回归灰阶，不再使用额外彩色强调。
- 诊断日志区可随窗口高度增长，并保留打开目录、清理日志和清空视图操作。

其他子窗口也完成统一：

- 去除系统标题栏，使用共享的自建标题区和右上角关闭按钮。
- 关闭、刷新、最小化和最大化图标统一使用圆角半透明悬停底。
- 画面、投屏、媒体输出、更新、启动错误和驱动恢复窗口共享同一边距与文字层级。
- 三种有线投屏方式说明窗口增高并支持滚动，长中文/英文提示不再显示不全。

## USB 配置失败恢复提示

本版本新增对以下稳定诊断片段的识别：

```text
[set_configuration] could not set config
```

该识别不依赖 `win error:` 后面的本地化文字，因此即使旧版 libusb0 返回 CP936 中文并在 UTF-8 界面中显示为乱码，也能准确匹配。

识别到该错误时，程序只显示一次本地化恢复提示，建议按顺序尝试：

1. 拔下数据线，等待几秒后重新插入。
2. 重启 iPhone 或 iPad 后重新连接。
3. 更换 Apple 原装或 MFi 认证数据线。

提示同时要求重新连接和开始投屏时保持设备解锁。该错误发生在 QuickTime USB 配置切换阶段，与进入端点后的 PING 握手超时是两条独立诊断路径。

## 驱动管理器

- 驱动管理器新增系统、浅色和深色主题选择，并使用主程序相同的共享主题资源。
- 外侧窗口现在显式应用 DWM 边框颜色；最大化时移除圆角和外边框，还原后恢复，与主窗口策略一致。
- 主窗口和所有驱动提示窗口均使用自建标题栏及统一关闭按钮。
- Apple 支持组件安装或服务恢复过程中取消 UAC 时立即停止，并显示明确的取消结果，不再继续进入通用失败流程。
- 驱动变更后的设备信任确认、失败帮助和必要操作窗口统一到新的子窗口布局。

## 独立预览与菜单

- 独立预览右键菜单按“窗口”“显示”“音频”重新分组。
- 全屏、置顶、固定尺寸、圆角、画面设置、旋转、静音和关闭命令更容易扫描。
- 菜单文字会在语言或窗口状态变化后刷新。
- 主预览和独立预览的全屏、最大化及恢复路径加强了边框和尺寸同步。
