# iPhoneMirror v1.8.5-pre

1.8.5-pre 预发布测试版，汇总 v1.8.3 以来的控制、界面、本地化及运行时改进。

## 新增与改进

- 统一键盘输入路由，新增按键映射向导与五点触控支持。
- 改善多设备输入隔离、剪贴板交互以及有线、无线和蓝牙反向控制的切换与恢复。
- 扩展繁体中文本地化，改善预览工具栏、自适应布局、托盘启动及主题显示。
- UxPlay 无线组件作为独立可选包提供，支持按需下载安装。

## 修复

- 改善 USB 连接恢复、旧版 iOS 配对兼容性及蓝牙输入卡顿后的恢复。
- 修复设备焦点切换后的过期输入、静态无线画面保留和预览重绘问题。
- 完善驱动工具、更新与运行时打包的稳定性检查。

## 测试说明

- 此版本标记为 GitHub Pre-release，供测试新功能和兼容性使用。
- 提供 Windows x64 安装版、便携版、UxPlay 可选组件、SBOM 和 SHA-256 校验文件。

### Added

- Unified keyboard routing, a key-mapping wizard, and five-point touch support.
- Expanded Traditional Chinese localization and an optional, downloadable UxPlay component.

### Changed

- Improve multi-device input isolation, clipboard workflows, preview layouts, tray startup, and theme consistency.
- Improve transitions and recovery across wired, wireless, and Bluetooth reverse control.

### Fixed

- Improve USB recovery, pairing compatibility with older iOS versions, and recovery from stalled Bluetooth input.
- Discard stale input after device focus changes and retain and redraw static wireless preview frames.
- Strengthen driver, updater, and runtime packaging checks.

### Notes

- This is a prerelease for feature and compatibility testing.
- Windows x64 installer, portable ZIP, optional UxPlay component, SBOM, and SHA-256 checksums are included.
