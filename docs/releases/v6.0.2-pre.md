# iPhoneMirror v6.0.2-pre

v6.0.2-pre 新增完整的繁體中文（香港）介面，涵蓋主程式、驅動程式管理員、
啟動錯誤視窗及 Windows 安裝程式。同時改善一鍵更新流程，避免使用者在安裝程式
尚未準備好取代檔案前失去正在使用的主程式。

## 語言與本地化

- 新增繁體中文（香港）語言選項，並為主程式 463 個資源項目及驅動程式管理員
  140 個資源項目提供完整翻譯。
- Windows 使用香港、澳門、台灣或其他 `zh-Hant` 系統文化時，自動選用香港繁體
  中文介面；簡體中文和英文選擇行為保持不變。
- 採用香港常用詞彙，包括「軟件」、「硬件」、「網絡」、「解像度」、「音訊」、
  「流動裝置」、「資料夾」及「解除安裝」，並使用 Microsoft JhengHei UI 字體。
- 本地化啟動失敗提示、原生元件載入說明及診斷記錄入口；香港繁體介面不再顯示
  原生核心傳回的簡體中文錯誤內容。
- 新增香港繁體 Inno Setup 安裝與解除安裝介面，包含開始功能表捷徑、使用者資料
  保留提示、檔案驗證、下載及錯誤訊息。

## 更新流程修正

- 啟動 Setup 後保留目前主程式，直到 Windows Restart Manager 到達檔案取代階段
  才關閉；若使用者取消權限提示，或安裝程式在早期失敗，主程式仍可繼續使用。
- 安裝完成後由 Setup 延遲重新啟動新版主程式，避免共享 .NET/WPF 執行階段仍被舊
  主程式或驅動程式管理員佔用。
- 便攜 ZIP 更新仍由更新輔助程式驗證並關閉相關程序，不改變既有覆蓋更新行為。

## 安裝程式與品質保障

- 固定 Inno Setup 6.7.3 繁體中文來源及轉換後檔案的 SHA-256，並以可重現方式套用
  香港詞彙和相容性修正。
- 本地化驗證會檢查三種語言的資源鍵、格式化佔位符、主題資源及香港用語。
- GUI 冒煙測試會實際切換英文、簡體中文和繁體中文（香港），核對視窗標題、主要
  操作文字及字體資源。
- 安裝器測試使用繁體中文完成舊版安裝、覆蓋升級、保留使用者資料解除安裝及刪除
  使用者資料解除安裝。

## 驗證結果

- Release 原生建置及 9 項 CTest 全部通過。
- 應用程式邏輯測試、WPF 執行階段測試和驅動程式管理員測試全部通過。
- VC 執行階段版本解析、Apple 支援套件、本地化一致性、安裝器升級與解除安裝，
  以及三種語言 GUI 切換測試全部通過。

### Added

- Add a complete Traditional Chinese (Hong Kong) interface for the main app,
  driver manager, startup diagnostics, and Windows Setup.
- Select the Hong Kong resources automatically for `zh-HK`, `zh-MO`, `zh-TW`,
  legacy `zh-CHT`, and other `zh-Hant` system cultures.
- Add deterministic, hash-pinned Hong Kong terminology conversion for the Inno
  Setup Traditional Chinese language file.
- Extend localization validation and GUI smoke coverage to all three supported
  interface languages.

### Changed

- Use Hong Kong terminology and Microsoft JhengHei UI throughout the new
  Traditional Chinese resources.
- Keep the current application running after Setup launches until Restart
  Manager reaches the file replacement stage.
- Let Setup restart the updated application only after shared runtime files are
  released and installation has completed.

### Fixed

- Prevent cancelled elevation prompts and early installer failures from closing
  the current application and making an update appear to remove the app.
- Prevent Simplified Chinese native diagnostics from leaking into the Hong Kong
  Traditional Chinese interface.
