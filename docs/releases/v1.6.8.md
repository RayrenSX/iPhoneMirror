# iPhoneMirror v1.6.8

v1.6.8 新增 AirPlay 纯音乐投放，修复录制视频播放速度偏快和程序关闭等待问题，
并针对无线音频丢包、重传与播放缓冲进行了完整的稳定性优化。

## AirPlay 音乐投放

- iPhone 或 iPad 无需启动“屏幕镜像”，可直接从音乐 App 或控制中心把音频投放到 Windows。
- 部分 RAOP 发送端不会发送通用连接回调；程序现在会在收到有效 PCM 音频后自动创建无线来源并启动会话。
- 新增音频专用 ALAC 解码路径，继续保留屏幕镜像 AAC-ELD 的原有处理方式。
- 主界面会显示独立的“AirPlay 音乐”状态、发送端名称、采样率和声道信息。
- 音量、静音和停止投放保持可用；截图、独立预览、刷新画面和全屏等视频工具在纯音频会话中自动禁用。
- 如果发送端随后开始屏幕镜像，程序会自动恢复视频预览和相关工具。

## 无线音频稳定性

- 为 RAOP 音频加入有界的丢包等待与重传恢复，减少 Wi-Fi 抖动导致的短暂静音和连续欠载。
- 未能恢复的数据包会按协商的 PCM 帧长度进行时钟补偿，避免错误推进播放时间。
- AirPlay 音乐使用独立的 WASAPI 网络抖动模式，提供约 500 ms 的有界队列、180 ms 启动缓冲和 400 ms 高水位。
- 播放发生欠载后会重新积累启动缓冲再继续，避免在数据不足时反复启动和中断。
- 无效或解码失败的音频不会再被上报为有效 PCM，降低异常数据影响后续播放的风险。

## 录制速度修复

- 录制视频帧数现在与实际经过的墙钟时间保持一致，不再只依赖定时器成功触发的次数。
- 当画面复制、缩放、FFmpeg 编码或管道写入短暂变慢时，会用最新帧补齐已经错过的固定帧率槽位。
- 同一帧只准备一次后再用于补帧，避免追赶编码进度时重复执行缩放和画布复制。
- 修复录制时间正常但成片时长偏短、播放看起来明显加速的问题。

## 立即关闭与后台清理

- 点击主窗口左上角关闭按钮后，主窗口、设置窗口以及原生独立预览窗口会立即从桌面消失。
- 界面隐藏后，程序进程继续在后台停止录制与推流、关闭虚拟摄像头、结束投屏会话并释放 USB 核心。
- 正常关闭继续保留 15 秒保护上限，Windows 注销或关机时使用 4 秒上限，避免第三方 USB 调用永久阻塞退出。
- 新增关闭顺序和窗口可见性回归检查，验证界面先隐藏、清理后退出，并保留 QuickTime 停止握手。

## 兼容性与验证

- 正式版面向 Windows 10/11 x64，支持从 v1.6.7 覆盖升级。
- 安装版与便携版均包含 AirPlay 音乐、录制时钟和关闭流程修复。
- 完整 Release 构建覆盖原生协议、应用逻辑、运行时和驱动安装器测试。
- 发布资产继续提供安装程序、便携 ZIP、SPDX 2.2 SBOM 和 SHA-256 校验清单。

### Added

- Add audio-only AirPlay music sessions with automatic RAOP source creation,
  ALAC decoding, localized playback state, and audio-specific controls.

### Changed

- Use bounded retransmission-aware buffering and WASAPI rebuffering for
  network audio without changing the low-latency wired playback policy.

### Fixed

- Keep recorded frame counts aligned with elapsed wall-clock time so temporary
  encoding delays no longer produce shortened, fast-playing recordings.
- Hide all managed and native windows immediately on close while bounded media,
  capture, and USB cleanup continues in the background before process exit.
