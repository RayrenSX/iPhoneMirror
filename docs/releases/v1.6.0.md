# iPhoneMirror v1.6.0

v1.6.0 调整 Windows 发布布局：安装版由主程序和独立驱动管理器共享外置
.NET/WPF 运行时 DLL，便携版仍然使用内置运行时的单文件 EXE。默认两种版本
都内置 FFmpeg 8 媒体输出运行时，因此录制、RTMP、SRT 和 WHIP 功能继续开箱即用。

## 用户可见变化

- 安装包从约 159.6 MB 降至约 87.4 MB，便携 ZIP 保留完整运行时和 FFmpeg，
  便携用户不需要额外安装 .NET。
- 保留 USB 有线投屏、AirPlay、音频、截图、录制、推流、OBS 输出、虚拟摄像头、
  多设备和独立窗口功能。
- 安装版保留五个 .NET 诊断运行时文件：`createdump.exe`、`mscordaccore.dll`、
  `mscordbi.dll`、`mscorrc.dll` 和版本化 DAC DLL。

## 更新与兼容性修复

- 安装升级和便携 ZIP 更新都会关闭主程序及独立驱动管理器，再替换共享运行时。
- 已安装副本自动选择 Setup，便携副本自动选择 ZIP；旧版单文件安装通过 Inno
  Setup 的 App Paths 注册信息继续识别。
- 升级和 ZIP 覆盖更新会清理旧版本遗留的 FFmpeg 文件。
- 外部 FFmpeg 会读取 `where.exe` 返回的全部候选路径，并在首次失败后重新检测，
  用户把 FFmpeg 加入 PATH 后无需重启程序即可重试。
- 下载分段、大小、SHA-256、重定向和中断文件清理均在更新流程中校验。
