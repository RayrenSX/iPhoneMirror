# iPhoneMirror v1.6.6

v1.6.6 改进了国内及 GitHub 连接受限网络中的自动更新下载速度。更新程序现在会对
GitHub 和 MoreTools 列出的全部 115 个镜像进行可达性检查与实际吞吐测试，选择当前最快的
线路下载，并在镜像异常时自动切换。

## 下载线路测速

- 对官方 GitHub 和 115 个 MoreTools 镜像先执行 HTTPS HEAD 可达性检查。
- 仅对可达线路下载 256 KB Range 样本，按实测吞吐量从快到慢排序。
- 正式更新优先使用最快线路，不再先等待 GitHub 完整文件下载失败。
- 当前线路连续 30 秒无下载进度，或出现网络、大小、重定向或校验异常时，立即切换到下一条已测速线路。
- 更新窗口会分别显示线路可达性检查、吞吐测速和正式下载状态。

## 安全与兼容性

- 发布元数据和 SHA-256 摘要仍只从官方 GitHub API 或 `raw.githubusercontent.com` 获取。
- 镜像只用于传输经验证的发布资产，不会放宽 HTTPS、重定向、文件大小或 SHA-256 校验。
- 未提供可信 SHA-256 的资产不使用第三方镜像。
- Release 继续面向 Windows 10/11 x64，安装版和便携版都包含本次更新逻辑。

### Changed

- Test GitHub and all 115 mirrors listed by MoreTools before downloading an
  update, then rank reachable routes using a 256 KB throughput sample.
- Fail over immediately through the measured route ranking on network,
  integrity, redirect, size, or 30-second download-stall failures.
- Keep official release metadata and SHA-256 verification authoritative for
  every mirrored download.
