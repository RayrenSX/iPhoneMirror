# iPhoneMirror v1.5.6

v1.5.6 进一步收紧高缩放 Windows 桌面上的窗口尺寸，并改善多设备、多投屏来源场景下的主界面导航。本版本不修改 USB Screen Capture、AirPlay、解码、音频、OBS 输出、虚拟摄像头或驱动安装协议。

## 高 DPI 窗口适配

- Windows 显示缩放高于 100% 时，超大窗口最多占用当前显示器可用工作区的 80%，在窗口四周保留可操作空间。
- 窗口宽度和高度分别按工作区限制，任务栏、停靠区域和多显示器负坐标继续纳入计算。
- 如果设计最小尺寸超过当前可用上限，会同步降低运行时最小尺寸，避免 WPF 最小尺寸把窗口重新撑出屏幕。
- 已经小于上限且位置有效的窗口不会被放大，也不会在 DPI 变化后无故重新居中。
- 窗口进入另一台不同 DPI 的显示器后会重新计算尺寸和位置。

## 主程序与驱动管理器一致性

- 将窗口工作区控制器移动到共享 UI 模块，主程序和独立驱动管理器使用同一份实现。
- 驱动管理器主窗口及其子窗口现在也会在加载和 DPI 变化后检查当前工作区。
- 共享实现减少两套程序在窗口最小尺寸、显示器边界和后续修复上的行为差异。

## 多来源导航

- 当第二个投屏来源加入时，主界面会自动打开“投屏来源”面板，便于立即选择新增设备或媒体投屏来源。
- 常规设备刷新、现有设备信息更新和设备移除不会强制切换面板。
- 如果“投屏来源”本来已经打开，不会重复执行切换，也不会写入误导性的“自动打开”诊断事件。
- 用户仍可手动在“投屏”和“投屏来源”之间切换；右侧投屏设置面板继续独立显示。

## 构建与维护

- GitHub Windows 构建工作流升级到 `actions/setup-dotnet@v6`。
- .NET SDK 继续由 `global.json` 固定为 10.0.301，并允许在同一 feature band 内向前滚动。
- 安装版和便携版继续采用 Windows x64 自包含发布，不要求目标电脑另行安装 .NET。
- 没有新增第三方运行时依赖，也没有修改用户设置文件格式。

## 兼容性与升级

- 支持 Windows 10 1809 及以上版本和 Windows 11 x64。
- 可直接覆盖安装 v1.5.5；主题、语言、更新选项和设备设置继续保存在 `%LOCALAPPDATA%\iPhoneMirror`。
- 公开发布包不包含 Apple Mobile Device Support、iTunes 或其他 Apple 专有二进制文件。
- 有线投屏仍需要 Apple Devices，或包含 Apple Mobile Device Support 的桌面版 iTunes。

## 已知限制

- 80% 窗口上限只在 Windows 显示缩放高于 100% 时启用；100% 缩放仍允许窗口使用完整工作区。
- 工作区面板状态不会跨应用重启保存，启动后默认显示“投屏来源”。
- 当前安装程序未使用商业 Authenticode 证书签名，Windows SmartScreen 可能显示“未知发布者”。请只从项目官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- QuickTime Screen Capture 与兼容 AirPlay 实现并非 Apple 官方稳定接口，未来 iOS 更新仍可能需要适配。
