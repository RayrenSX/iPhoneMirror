# iPhoneMirror v1.6.5

v1.6.5 重点重构 USB 有线投屏的启动、设备重枚举和停止恢复流程。新版本会按具体设备
串行处理会话生命周期，在 USB 配置切换期间暂停可能干扰状态判断的设备枚举，并结合
序列号、拓扑、PnP 接口变化、描述符和 usbmux 状态确认目标设备，减少重复启停、双设备
并行使用和复杂 Apple/libusb0 驱动组合下的误判、黑屏与残留会话。

## USB 投屏生命周期

- 新增独立的 `iPhoneMirror.UsbConfigurationSwitch.exe` 配置切换组件，将真实 Apple USB
  配置请求与主进程会话隔离；安装版和便携版都会携带并校验该组件。
- 启动前按目标设备的完整序列号和物理父节点检查 libusb0 可见性，不再用另一台已连接
  iPhone 的全局驱动状态推断当前设备可用。
- 同时存在 Apple 内核过滤器和 libusb0 时不再直接阻止投屏，而是使用更保守的打开、
  激活和清理顺序，并在界面显示明确的驱动状态。
- USB 配置变化期间暂停常规有线设备枚举；只有显式空闲刷新才读取 Lockdown 元数据，
  避免设备重枚举与属性查询互相干扰。
- 停止投屏时先撤销可见会话句柄，再释放预览、解码器、USB 接口和配置；多个停止请求
  会共享同一个清理任务，不会重复关闭同一原生会话。
- 恢复普通 Apple USB 配置时结合目标设备消失/重新出现、PnP 接口顺序和连续稳定观测，
  必要时只执行一次受控回退，降低残留 QuickTime 配置或误操作其他设备的风险。

## 多设备与重复启停

- 每台设备独立串行处理启动和停止操作；某台设备正在清理时，其他设备仍可提交操作，
  同一设备的新请求会排队并保持绑定到最初点击的设备。
- 设备卡片新增“正在清理”和“等待设备清理”状态，切换选择时不会把正在销毁的会话
  重新呈现到预览窗口。
- 改进双设备并行投屏时的序列号和 USB 拓扑关联，避免一台设备的 QuickTime 接口、
  usbmux 状态或重枚举事件被另一台设备错误采用。
- 新增单设备连续“启动、停止、重新发现、再次启动”实机冒烟流程，并扩展双设备切换、
  窗口关闭和配置恢复测试。

## 错误提示与诊断

- 原生 API 升级到 v18，捕获状态现在携带失败类型、失败阶段和错误码，可区分 USB 预检、
  配置激活、设备重枚举、接口打开、QuickTime 握手、视频流、解码和会话清理等阶段。
- 界面提供简洁的本地化恢复建议，分别处理断线、驱动异常、无画面、超时、重复会话和
  清理未完成等情况；原始错误码、阶段和详细诊断仍完整写入日志。
- 检测到用户从 iPhone 或 iPad 控制中心停止镜像时，会使用专门提示说明再次有线投屏前
  需要重启设备，不再把它误报为普通拔线。
- 如果停止后已释放所有应用资源但未能确认普通 USB 配置恢复，会显示独立警告和诊断，
  不再套用通用停止失败提示。

## 界面与构建

- 未处于有效投屏状态时收起预览工具栏，避免截图、旋转、全屏和显示设置等操作看似可用。
- 自绘标题栏按钮补充本地化工具提示，并修正提示窗口最大化/关闭状态同步。
- 发布包新增 USB 配置切换组件的存在性检查；默认构建不再生成会对真实设备发起配置或
  批量传输请求的压力测试工具，只有显式启用危险工具选项时才会构建。

## 验证与兼容性

- 支持从 `v1.6.3` 安装版覆盖升级，也支持便携版应用内更新；用户设置、录制目录和驱动
  配置保持不变。
- Release 继续面向 Windows 10/11 x64，包含 USB 与 AirPlay 投屏、音频、录制/推流、
  虚拟摄像头和独立驱动管理器。
- 自动化覆盖原生 CTest、应用逻辑、WPF 运行时、驱动管理器、安装升级、发布资产校验、
  USB 配置恢复策略、设备刷新策略、并发清理与结构化错误映射。

### Added

- Add structured capture failure kinds, stages, and error codes across the
  native API, managed UI, logs, and lifecycle diagnostics.
- Add an isolated USB configuration switch helper to installed and portable
  packages.
- Add localized recovery actions for connection, driver, stream, decoder,
  timeout, duplicate-session, disconnect, and phone-closed failures.

### Changed

- Serialize lifecycle work per device, queue requests behind teardown, and
  revoke handles before native cleanup begins.
- Pause wired enumeration and metadata refresh during USB configuration
  transitions, then require stable exact-device evidence before rediscovery.
- Use a conservative capture path when Apple kernel filters and libusb0 are
  stacked, while keeping the installed drivers unchanged.
- Hide preview-only controls outside active mirroring and expose queued and
  cleanup states during transitions.
- Keep real-device USB stress probes out of default builds unless explicitly
  enabled.

### Fixed

- Restore normal Apple USB configuration reliably across repeated start/stop
  cycles, application shutdown, and concurrent multi-device sessions.
- Prevent stale and cross-device USB matches by correlating serial, topology,
  PnP transitions, descriptor state, and usbmux presence.
- Coalesce concurrent stop requests and prevent background errors or window
  shutdown from destroying and reusing a native session twice.
- Distinguish a phone-side mirroring stop from a cable disconnect and show the
  correct recovery action without exposing raw diagnostics in prompts.
- Bound socket shutdown waits and tighten QuickTime control-channel cleanup so
  teardown cannot wait indefinitely on a stalled peer.
