**v1.8.5-pre7 是 iPhoneMirror 1.8.5 正式發行前的最後一個預覽版**，適用於 Windows x64。以下是自 v1.8.5-pre6 以來的主要變更。

### 鏡像與裝置連線

- 新增已配對無線裝置探索。同一支手機的有線和無線狀態會顯示在同一張裝置卡片。
- 新增實驗性 CoreDevice 無線鏡像，目前僅傳送畫面。需要 iOS／iPadOS 27 或更新版本、裝置綁定、開發者模式和相符的開發者映像。
- USB 鏡像提供建議的原生 AirPlay 模式與相容的示範模式。先前儲存的固定尺寸 C 模式會移轉至原生 AirPlay。
- 在相容的 USB 鏡像連線中，可以將聲音留在手機播放。電腦錄影或直播將無法擷取該裝置的聲音。遊戲麥克風相容性仍需實機驗證（#100）。
- 解析度、影格率和解碼器設定會自動儲存。色彩編輯及無線接收設定仍須個別儲存或套用。

### 預覽、檔案與獨立視窗

- 可在預覽中複製畫面文字、傳送檔案，或拖入 IPA 後選擇傳送或安裝。安裝需要有效的簽署及裝置授權。
- 擴充 Windows 檔案總管對應，集中顯示裝置允許存取的媒體、當機記錄和應用程式資料夾，並保留讀寫權限。
- 可依裝置記住上次使用的獨立視窗配置、儲存預設配置及自訂位置。可在快速鍵設定中配置視窗動作和 Windows 快速鍵規則（#91、#92、#93）。
- 修正部分圓角對話方塊的角落被擁有者視窗背景填滿的問題，並保留透明覆疊視窗的背景效果。
- 修正在同一部裝置的 UDID 大小寫或連字號不同時，有線反向控制、設定檢查和檔案存取可能找不到裝置的問題。
- 修正顯示手機外框時滾輪失效、預覽旋轉後捲動方向錯誤，以及滾輪和滑鼠拖曳互相中斷的問題。

### 使用與相容性

- 完整設定精靈新增免費開放原始碼說明，以及可略過的支持作者頁面。
- 應用程式的更新說明跟隨介面語言。GitHub Release 預設顯示英文內容，並提供獨立的簡體中文連結。
- 使用指南補充兩種 USB 鏡像模式、配對後的無線鏡像、預覽工具及獨立視窗的操作步驟。實機驗證範圍請參閱各項功能說明。
- 主程式與驅動程式管理員的產品版本統一為 `1.8.5-pre7`。
