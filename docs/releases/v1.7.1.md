# iPhoneMirror v1.7.1

v1.7.1 improves the handling of video surfaces that iOS does not allow to be
captured, and makes capture failures easier to understand and recover from.

## 受保护视频与持续黑屏

- The wired capture pipeline waits for normal video frames before evaluating a
  later black transition.
- A possible protected-video state requires at least eight seconds and 24
  sampled near-black frames, with both luma and neutral-chroma checks.
- Audio is not required: protected playback may continue sending USB audio or
  may provide no audio at all. The notice reports the observed audio state.
- The notice uses cautious wording because a long black scene, a black page,
  the lock screen, decoder failure, and video-output failure can look similar.
- Normal video returning for two consecutive frames automatically closes the
  notice and hides the preview overlay without disconnecting the session.

## 紧凑采集提示

- Ordinary mirroring failures use a concise red error notice with a direct
  retry action.
- USB configuration failures use a distinct amber notice with a USB icon and
  cable reconnection guidance.
- A session stopped from Control Center uses a separate amber stopped notice
  with the required device restart guidance.
- Capture recovery keeps the native Windows/DWM outer corners and no longer
  draws a duplicate bright border around the window.

## 开发者工具

The read-only Developer Tools catalog now includes previews for:

- ordinary mirroring errors;
- Control Center stopped-session notices;
- USB mirroring configuration errors;
- protected-video notices;
- capture recovery guidance;
- the existing settings, output, update, startup, instance, and preview windows.

All previews use isolated sample data and do not perform device, network,
driver, update, or destructive operations.

## 验证

- Windows x64 Release native CTest: 10/10 passed.
- Application logic tests passed.
- WPF runtime tests passed.
- Driver installer, Visual C++ runtime, Apple support package, and release
  payload validation passed.
- Portable package, installer, SPDX SBOM, and SHA-256 asset manifest generated
  by the release scripts.

本版本不会绕过 Apple FairPlay，也不会让 iOS 拒绝提供的受保护画面变得可采集；
它只会在 iOS 提供持续黑色视频画面时给出清晰、可恢复的说明。

### Added

- Add sustained black-video detection for wired capture after a normal-frame warm-up.
- Add compact protected-video, capture-error, USB-configuration, and stopped-session notices.
- Add Developer Tools previews for the new notices and capture recovery guidance.

### Changed

- Require an eight-second, multi-frame near-black and neutral-chroma signal before showing the
  protected-video notice, reducing false positives from startup, short black scenes, and dark UI.
- Keep Windows/DWM outer corners for recovery and status notices while retaining compact internal
  status panels.
- Keep failed-session cleanup before ordinary error notices, and start stopped-session cleanup
  after the notice has been shown.

### Fixed

- Replace unexplained black video surfaces with cautious, recoverable guidance that does not claim
  DRM was definitively detected.
- Close protected-video notices and overlays automatically after normal video returns or a device
  switch.
- Remove duplicate custom borders that produced bright rings around native window corners.
