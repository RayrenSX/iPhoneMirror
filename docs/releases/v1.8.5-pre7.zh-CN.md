v1.8.5-pre7 是 **iPhoneMirror 1.8.5 正式发布前的最后一个预览版**，面向 Windows x64。以下是自 v1.8.5-pre6 以来的主要变更。

### 投屏与设备连接

- 新增已配对无线设备发现。同一台手机的有线和无线状态合并到一张设备卡片。
- 新增实验性 CoreDevice 无线投屏。此方式目前仅提供画面，需要 iOS／iPadOS 27 及以上、设备绑定、开发者模式和匹配的开发者镜像。
- USB 投屏提供推荐的原生 AirPlay 和兼容 Demo 两种模式。此前保存的固定尺寸 C 模式选择会迁移到原生 AirPlay。
- 支持在适用的 USB 投屏中将声音留在手机。使用此选项时，电脑录制或直播无法采集该设备的声音。游戏内开麦兼容性仍需实机验证（#100）。
- 分辨率、帧率和解码器设置改为自动保存。色彩编辑和无线接收设置继续使用各自的保存或应用操作。

### 预览、文件与独立窗口

- 在预览中复制画面文字、发送文件，或拖入 IPA 后选择传输或安装。IPA 安装需要有效签名和设备许可。
- 扩展 Windows 资源管理器映射，统一展示设备允许访问的媒体、崩溃日志和应用目录，保留设备报告的读写权限。
- 独立窗口支持按设备记住上次布局、保存预设和自定义位置。可在快捷键设置中配置窗口动作及独立窗口内的 Windows 热键规则（#91、#92、#93）。
- 修复部分圆角对话框角落被宿主窗口背景填充的问题，保留透明覆盖窗口的背景效果。

### 使用与兼容性

- 完整设置向导增加免费开源说明和可跳过的作者支持页。
- 应用内更新说明随界面语言切换。GitHub Release 默认显示英文正文，并提供独立的简体中文链接。
- 使用指南补充了两种 USB 投屏模式、配对无线投屏、预览工具和独立窗口的操作步骤。具体实机验证范围见相应功能文档。
- 主程序与驱动管理器的产品版本统一为 `1.8.5-pre7`。
