**v1.8.5-pre7 は iPhoneMirror 1.8.5 正式版に向けた最後のプレビューです。** Windows x64 向けで、v1.8.5-pre6 からの主な変更は以下のとおりです。

### ミラーリングとデバイス接続

- ペアリング済みのワイヤレスデバイスを検出し、同じデバイスの有線と無線の状態を一つのカードに表示します。
- 試験的な CoreDevice ワイヤレスミラーリングを追加しました。現在は映像のみで、iOS／iPadOS 27 以降、デバイスの関連付け、デベロッパモード、対応する開発者用イメージが必要です。
- USB ミラーリングには推奨のネイティブ AirPlay モードと互換性重視のデモモードがあります。固定サイズの C モードを保存している場合は、ネイティブ AirPlay に移行します。
- 対応する USB 接続では、音をデバイス側で再生できます。この設定中は Windows の録画や配信にそのデバイスの音声を取り込めません。ゲーム内マイクとの互換性は実機での検証が必要です（#100）。
- 解像度、フレームレート、デコーダーの設定を自動で保存します。色調整とワイヤレス受信設定は、それぞれの保存または適用操作で反映します。

### プレビュー、ファイル、独立ウィンドウ

- プレビューから画面上の文字をコピーしたり、ファイルを送信したりできます。IPA をドロップした際は、転送またはインストールを選べます。インストールには有効な署名とデバイスの許可が必要です。
- エクスプローラーのマッピングを拡張し、アクセス可能なメディア、クラッシュログ、アプリのフォルダーをまとめて表示します。デバイス側の読み書き権限も維持します。
- デバイスごとに独立ウィンドウの前回のレイアウトを復元でき、プリセットとカスタム位置も設定できます。ウィンドウの操作と Windows ホットキーの規則はショートカット設定から変更できます（#91、#92、#93）。
- 一部の角丸ダイアログの隅に親ウィンドウの背景が描画される問題を修正しました。透明なオーバーレイの背景は維持されます。

### セットアップと互換性

- セットアップウィザードに、無料のオープンソースソフトウェアであることを案内するページと、スキップできる作者支援ページを追加しました。
- アプリ内の更新内容を現在の表示言語で表示します。GitHub のリリースページは英語で表示し、簡体字中国語版へのリンクを掲載します。
- ユーザーガイドに、USB の二つのモード、ペアリング済みの無線デバイス、プレビューツール、独立ウィンドウの操作を追加しました。実機での確認範囲は各機能の資料に記載されています。
- アプリケーションとドライバー管理ツールの製品バージョンを `1.8.5-pre7` に統一しました。
