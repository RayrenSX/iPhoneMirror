## 三大类步骤整理（2026-10-08）

顶部进度统一为「基础设置 → 设备连接 → 投屏体验」，不再因用途分支显示五或七个阶段。

## 使用流程优化（2026-10-08）

| 问题 | 调整 |
| --- | --- |
| 返回无线、蓝牙步骤后必须重新配置 | 核对检查点与磁盘档案，已保存的绑定可直接继续，保留重新配置入口 |
| 点击无线选项立即下载并隐藏选项卡 | 选择只保存草稿，点击下一步才下载缺失组件 |
| 驱动正常或检查取消后仍只提供安装操作 | 提供只读重新检测，仅检测缺失时显示安装说明和按钮 |
| 取消扫描后沿用旧清单，迟到结果可能重新启用下一步 | 取消立即撤销可继续状态，忽略该扫描的迟到结果 |
| 关闭发现页过早释放助手状态 | 等待扫描清理后再释放主窗口刷新与助手入口 |
| 多设备的无线接收方式页缺少设备上下文 | 按实际设备步骤判断并显示当前设备名称、序号 |
| 延后配置保存失败后仍保留 Deferred 状态，部分保存错误提示不可见 | 回滚原状态并显示保存失败提示 |

## 本轮修复

| 问题 | 修复行为 |
| --- | --- |
| 跳过身份读取或档案保存后返回，进入没有前置身份的绑定页 | 返回对应被跳过的身份步骤；恢复不完整检查点也检查前置条件 |
| 纯无线跳过绑定仍应用无线设置 | 仅已记录无线绑定时应用接收设置或进入无线画质页 |
| 再次运行保留完成状态、设备索引及重启提示 | 已完成向导重新运行时建立干净状态 |
| 保存失败只回滚页码，遗留目标页的跳过记录或已完成标记 | 导航完整回滚状态，结束失败还原完成标记，步骤保存失败清除成功记录 |
| 无线选项只在内存中，关闭恢复后丢失 | 接收方式、画质草稿进入检查点并恢复 |
| 切换用途清掉已跳过的语言等公共步骤 | 只清理分支相关状态 |
| 取消检测时底层探测继续执行，迟到结果可能影响下一步 | 保留所有权至探测结束，再完成取消；驱动进度回调检查当前步骤和取消状态 |
| 视频偏好写入失败仍留在已保存设置的内存副本 | 保存失败回滚该副本 |
| 结束后沿用旧选中设备，可能启动本次未配置设备 | 只选择本次已保存且仍在列表的设备；没有匹配设备则进入主界面 |
| 运行无线控制时仍可打开助手 | 纳入现有活动会话检查 |
| 驱动 IPC 非取消异常未清理助手 | 通信异常同样进入清理路径，只读助手可结束，安装事务仍安全退出 |
