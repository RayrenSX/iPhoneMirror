# 第三方组件与许可

[文档索引](../README.md) · [完整英文第三方声明](../../THIRD_PARTY_NOTICES.md)

iPhoneMirror 自有代码使用 GPL-3.0-only。第三方组件继续适用各自许可。包内实际组件和版本以对应发行包的声明、清单及随包许可为准。

| 组件 | 用途与来源 |
| --- | --- |
| iUsbBridge 及其 Python 依赖 | 反向控制及设备管理。独立桥接器使用其单独的许可。 |
| libusb-win32 与 Apple USB 支持 | 有线采集过滤器、设备信任和 USBMux 支持。驱动管理器分别验证驱动和服务。 |
| 内置 AirPlay 接收端、可选 UxPlay 和 FFmpeg | 无线接收、媒体解码和输出。具体组件取决于构建选项。 |
| IPA 签名工作进程 | 集成 iPASide 的部分 MIT 授权模块，完整声明与上游版本记录随包提供。 |
| 手机边框素材 | 图像来源因机型而异，完整出处、修改说明和许可由第三方声明记录。 |
