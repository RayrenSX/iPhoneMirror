# 支持 iPhoneMirror

[文档索引](../README.md) · [English donation guide](../en/DONATE.md)

iPhoneMirror 免费开源。赞赏完全自愿，用于支持开发和维护。首次设置可以跳过作者支持页，也可以在「关于 → 支持作者」随时打开。

请用对应支付应用扫码。手机端可以保存原图后用相册识码。付款前核对收款人，收款码显示的名称为「修仙之道上的翔（**翔）」。
