# rPlayHub 集成：功能复核与保留范围

核验日期：2026-11-15。以当前可执行代码与实机返回为准，不再把「已接入」当作「已可用」。上游参考版本保存在 [来源说明](../third_party/rplayhub/README.md)。

## 实机检查

设备：iPhone 17（iPhone18,3 / iOS 27.2）、iPhone 12 mini（iPhone13,1 / iOS 18.7.8）。检查使用明确选中的设备通道；没有替换正在运行的旧程序。

| 功能 | 结果与处理 |
|---|---|
| 设备信息、电池、存储 | 两台设备三个域均成功返回；保留 |
| App 枚举与筛选 | 两台 CoreDevice 列表分别返回 184 / 161 项；安装服务只读枚举分别返回 391 / 327 项（包含范围不同）；保留 |
| 打开 App | 两台均成功通过 AppService 单次打开系统设置，`kill_existing=False`；保留双击、Enter 和右键打开 |
| 图标 | iPhone 12 mini 实际返回有效 PNG；相同 SpringBoard 服务封装与图标缓存有回归覆盖；保留 |
| 进程列表 | 两台分别返回 385 / 307 个进程；保留。结束进程有白名单、租约和单次分发检查，未结束用户进程 |
| 描述文件列表 | 两台分别返回 14 / 0 项，服务错误为空；保留 |
| 媒体文件与报告 | 两台 RSD 通道均成功浏览报告；媒体目录均成功浏览。iPhone 12 mini 实际分块读取 200 字节并通过边界检查；保留 |
| 实时日志 | 两台订阅启停成功；iPhone 12 mini 实际轮询得到 2 条日志并确认运行；保留 |
| 手机设置 | 两台均能读取大部分设置。iOS 18 的 Liquid Glass 等不可用项直接移除显示；只显示读取成功的编辑项 |
| 模拟定位 | 两台均公布独立 locationservice，精确 XPC 结构、输入边界、取消和恢复调用有协议测试；保留，未改变用户的真实定位状态 |
| 主屏幕、锁屏、音量等 | 复用现有已验证 HID 输入路径；取消时释放按钮的协议回归通过；保留 |
| IPA 安装 / App 卸载 | 分块暂存、真实 PMD 调用、签名拒绝、上传权限与清理测试覆盖；保留，安装失败显示签名 / 许可提示。本轮未安装或删除用户 App |
| 描述文件安装 / 移除 | Misagent / MCInstall 结构、配置存在性、确认及清理有回归；保留。本轮未改变用户的描述文件 |
| 重启、关机、休眠 | 使用现有 Diagnostics 服务、明确确认和动作白名单；保留。本轮未对用户手机执行电源测试 |
| Python SDK / MCP | 真实 HTTP 测试与实际 stdio MCP 会话通过；保留 36 个工具及对应 SDK 方法，设备管理桥剩余 26 项动作，其中公开 24 项 |
| 离线编码流重放 | 内部 18 帧及尺寸变化测试曾通过；2026-11-16 按用户要求移除桌面入口与会话启动路径，新交付包不再附样本 |
| 原生 HEVC / AAC 媒体及其录制 | iOS 18 支持掩码为 0；iOS 27 支持掩码为 972，但实机重复以 9022 拒绝启动，结束通话后仍未取得可用画面；删除原生投屏、其音频开关、状态和依赖的 HEVC/RTP 录制功能 |

已删除功能同步从右侧面板、旧实验室、HTTP/OpenAPI、桥动作清单、Python SDK/MCP 清除。旧重复实验室窗口整体移除；开发者工具入口与左侧导航均使用统一右侧面板。常规 USB/AirPlay 投屏、原有录像和截图不受删除影响。

## 界面及连接回归

- 应用、进程、描述文件和文件右键直接操作所指条目；空白处不复用旧选择；旧设备菜单不能操作新设备。
- 搜索、筛选、图标加载、单次 App 启动、文件夹打开、日志清理与过期响应取消。
- 投屏导致普通枚举退回 Paired 时保留管理列表；三轮断线/重连自动恢复当前页与选择；恢复中的旧请求不得覆盖新列表。
- 六个页面刷新时的浅/深主题截图；暗色禁用状态像素检查，避免白底闪现。
- 五种语言、六页、两种主题、紧凑窗口及轻量模式布局；三类常规设置回归。

实机正向验证与协议验证分开记录。未执行删除、安装、电源等可能影响用户设备的实机操作，不将其写成全量实机通过。

入口与构建见 [设备管理说明](DEV_DEVICE_HUB.zh-CN.md)，脚本调用见 [SDK/MCP](../sdk/python/README.md)。
