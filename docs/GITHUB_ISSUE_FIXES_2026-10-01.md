## 使用方法

- **直播麦克风**：打开“输出设置 → 直播推流”，向下滚动到“直播麦克风”。选择设备后开始推流；选择“不使用麦克风”可保持仅手机声音。新增麦克风后点击“刷新麦克风”。建议佩戴耳机避免回声。
- **桌面精简启动**：先选择手机，在“投屏设置”中点击创建当前设备桌面快捷方式。再次点击快捷方式会打开或激活对应的独立窗口。
- 命令行：`iPhoneMirror.exe --compact --device "设备 UDID"`。仅有一台可枚举设备时可省略 `--device`。多台设备且未指定目标时给出提示，不会随意选择；设备发现有约 20 秒等待预算，实际会话连接仍走现有连接流程。此入口用于已能被应用枚举的 iPhone/iPad，不代替 AirPlay 发射端主动连接。
