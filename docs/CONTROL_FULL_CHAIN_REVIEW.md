# 有线 / 无线控制全链路复审（2026-10-07，第二轮）

本轮接续 `CONTROL_TRANSPORT_REVIEW.md`，检查入口绑定、主程序进程生命周期、
USB / Network usbmux、RemotePairing、DDI 下载与挂载、RSD 身份、HID / Indigo、
输入会话编号、断线恢复、停止及再次启动。没有改动用户的键盘挂钩及首次设置工作。

## 新发现与修复

| 优先级 | 触发条件与影响 | 修复 |
|---|---|---|
| P1 | Network usbmux 能找到设备，但 CoreDevice 建隧道断开或超时；原流程直接失败，遗漏独立的无线连接方式 | 在尚未 ready 的可恢复传输故障后继续 RemotePairing；USB 不改走无线，已建立会话的故障仍交给恢复流程 |
| P1 | DDI 刷新逐文件覆盖共享缓存；取消或其他设备并发挂载可能读到新旧混合文件 | 将完整、复核通过的镜像包发布到不可变目录，再原子切换小型指针；返回本次验证的路径，原有挂载路径始终保留 |
| P2 | RemotePairing 的 close 被外层取消，底层 writer 未中止却已丢失引用 | 异常和取消均中止 writer；继续传播取消，清空引用 |
| P2 | DDI 发布到本地磁盘失败被当作下载网络故障 | 新增缓存写入错误码和简体中文、繁体中文、香港繁体、英文操作提示 |

DDI 快照保留旧格式缓存兼容、文件完整性校验和按设备/系统区分的拒绝记录。
旧快照有意保留，避免删除其他桥接进程正在签名或上传的文件；本轮不引入自动清理。
