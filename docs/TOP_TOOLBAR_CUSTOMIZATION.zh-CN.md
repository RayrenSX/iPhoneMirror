# 顶部工具栏自定义

入口保持在应用设置“自定义顶部工具栏”和工具栏右键菜单。原来的8个功能和主界面单行布局保留，没有整窗布局管理器。

## 编辑

原工具栏可见时，进入编辑会让主界面平滑向上放大，四周以柔边黑色渐变暗下去。原工具栏隐藏时（轻量模式或手动隐藏），编辑栏从上方轻微滑入并淡入，背景只渐暗、保持原位；退出时向上淡出，不生成虚构的工具栏起点或返回图片。视觉效果使用固定值，不提供视觉参数面板。日常工具栏直接使用原来的主题背景，没有额外颜色、模糊或自动隐藏层；此前保存的 VisualEffects 不再生效，按钮顺序和仅图标设置继续保留。

聚焦后，8个工具按自然宽度完整横向排开，随可用宽度适配比例，没有两端箭头、横向滚动条或换行。窗口或文字尺寸变化时重新适配。底部只保留组件库、仅图标、恢复默认、取消和完成；组件库默认关闭，打开时才显示原有8个功能。

编辑层始终覆盖主窗口，随最大化、全屏、还原和拉伸同步尺寸，不单独套用普通设置窗口的工作区缩放限制。位置按屏幕物理像素同步，窗口圆角跟随主窗口；移动窗口复用背景，尺寸变化合并刷新，避免右侧或底部露出未暗化的主界面。

按住工具并移动即可拖动排序。移动超过正常点击阈值后显示跟随指针的浮动卡片，原位置保留淡化占位；其他工具按插入位置调整。松手保留当前顺序，按 Esc 或失去鼠标捕获撤销当前这次拖动。点击工具后只显示名称与隐藏；隐藏的工具可从组件库找回。最后一项隐藏后自动打开组件库。键盘仍支持 Delete 隐藏和 Alt+左右调整顺序。

完成会保存按钮顺序和仅图标设置，重启后恢复。取消／关闭恢复本次编辑前的配置，再反向退出当前编辑动画。编辑期间不执行快捷工具的真实业务命令。Esc 优先取消拖动，再收起组件库，最后退出编辑。

## 实现与验证

继续复用 WPF 编辑窗口与内存场景过渡，投屏会话和原生窗口结构未改。聚焦背景是进入时的静态快照，有可用视频帧时合成进去；退出恢复实时界面。拖动使用原生 WPF 鼠标捕获和浮动图层，不创建额外弹窗或更换业务按钮实例。

视频帧按原始像素比例等比居中合成到预览区域，空余部分保留黑边，不拉伸填满整个预览框；合成快照保留主界面的分辨率和 DPI。进入、编辑和退出均不修改视频源或原生投屏渲染器。

此前专项验证的本机产物目录为 `outputs/iPhoneMirror-main/review-toolbar-slide/release`，日志与截图在相邻 `validation`，不随仓库分发。当前主线统一交付根目录为 `outputs/iPhoneMirror-main`，以实际交付内容为准。专项覆盖真实控件上的路由按下与捕获、拖动阈值、双向插入、路由松手、失去捕获、Esc 还原、持久化、取消和原按钮身份；另覆盖5种语言、深浅主题及150%文字下的整行显示。测试用程序坐标驱动拖动更新，不向系统或实体手机注入鼠标输入。真实鼠标端到端操作、物理跨屏DPI和实体iPhone持续视频尚未现场验收。

## 动画流畅度

聚焦临时窗口改为普通不透明WPF窗口，使用渲染变换与透明度的动画时钟；不再依赖逐帧托管回调计算矩阵、渐变和布局。背景在进入时只截取一次，退出沿用同一张背景，仅更新小块工具栏图片。柔边遮罩提前生成最长边768像素的渐变纹理，主界面图片、图标与文字保持原本的DPI；该纹理只用于暗化。

原工具栏可见时，进入使用360毫秒缓出，正常退出280毫秒；隐藏时改为240毫秒滑入、200毫秒退出，位移14 DIP且不缩放背景。工具栏预览和底部操作栏在同一段过渡内出现。中途取消从当前变换反向衔接，不等进入播放完；动画完成后清理时钟，恢复精确的最终状态。支持硬件渲染时临时缓存工具栏和底部操作栏，软件渲染回退时避免额外缓存开销。

拖动时原有卡片及集合保持不变，邻项用140毫秒的渲染位移动画让位，浮动卡片也只更新渲染位置。松手后一次提交顺序，避免每跨过一个工具都重新布局主窗口或重建整排预览。只在超过拖动阈值后捕获浮动卡片图片，普通点击不截图。

`--toolbar-motion` 与 `--toolbar-motion-default` 分别检查软件渲染和默认渲染：活动帧内额外布局与整窗截取为0、渐变纹理复用、预览衔接对齐、退出背景复用、提前反向、时钟清理、拖动时控件复用。`motion-metrics.json`记录准备耗时、退出启动耗时和WPF合成回调间隔；这些数据不是物理显示器呈现帧率，不能据此宣称所有设备达到60FPS。

整体编辑流程曾参考 ClassIsland，来源记录保留在第三方声明。当前拖动采用项目内的 WPF 鼠标捕获实现，不包含容器、分组、分隔线或额外功能。
