# 后续升级计划

本文件只记录尚未完成的计划，不代表当前版本已经实现，也不作为功能承诺。当前基线为
`v1.8.1`（2026-08-30）；已落地能力请以 README、使用教程和架构文档为准。

## 当前基线（v1.8.1）

- USB 与 AirPlay/DLNA 共用设备、预览、音频和输出工作流，支持 AirPlay 音乐及视频应用投屏；
- 主预览和独立窗口使用 D3D11/DirectComposition，Media Foundation 支持自动、硬件优先和软件兼容策略；
- 内建 MP4、RTMP、SRT、WebRTC/WHIP 输出，默认携带 FFmpeg 8.1.2；Windows 11 Media Foundation 虚拟摄像头已可安装和启动；
- 蓝牙反向控制支持按设备绑定、全局快捷键、系统导航和多设备路由；
- 管理员安装版自动维护无线宿主的本地子网防火墙规则，发布流程生成并校验 Setup、ZIP、SBOM 和 SHA-256 清单。

## 1. 稳定性与兼容性

- 建立 Windows 10/11、Apple Devices、不同 iOS 版本和 USB 芯片组合的干净环境测试矩阵。
- 增加断线、锁屏、拔线、快速重连和多设备同时停止的自动化回归测试。
- 为驱动安装、修复和卸载补充失败回滚、权限异常和重启后恢复测试。

## 2. 无线 AirPlay

- 增加网络带宽、丢包、解码队列和实际帧率监控。
- 根据网络状态提供可选的自适应清晰度建议，不自动改变用户已经确认的广播规格。
- 完善 iPhone、iPad 和不同系统版本的握手型号映射，并为未知 ProductType 提供可维护的本地映射表。
- 评估 IPv6、企业 Wi-Fi 隔离和多网卡环境下的发现与连接策略。

## 3. 有线投屏与画质

- 继续验证 A/B/C 模式在新 iOS 版本上的画面输出和视频 App 行为。
- 为高级 USB 尺寸提供安全预设、恢复默认值和失败后的自动回退。
- 增加渲染帧率、解码帧率和源设备分辨率的分层诊断，避免把本地渲染限制误认为源码流降质。

## 4. 采集与创作工具

- 扩大内建录制与 RTMP、SRT、WebRTC/WHIP 输出的长时间音画同步和弱网回归矩阵。
- 增加截图格式和连续截图策略，同时继续保证截图不包含软件 UI。
- 优化多设备独立预览的布局、窗口记忆和 OBS 场景配置辅助。

## 5. 发布工程

- 接入商业 Windows Authenticode 签名；发布包哈希、SBOM 和载荷完整性校验已在当前流程中启用，继续扩大异常场景覆盖。
- 扩大 GitHub Actions 在交互式 Windows 环境中运行 WPF 运行时和真实设备相关测试的覆盖；
- 增加升级说明模板和回滚说明，区分正式版、预览版与驱动组件版本。

## 6. 用户体验

- 完成无障碍名称、键盘导航和高 DPI 的系统化回归检查。
- 统一所有错误、确认、权限和重连提示的可操作建议。
- 继续补充教程截图，所有截图在公开发布前移除 UDID、序列号、通知和日志中的个人信息。
